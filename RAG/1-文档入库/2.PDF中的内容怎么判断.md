# PDF 中的内容怎么判断

## PDF 的页面模型

PDF 常见的来源与组合包括：

- 原生 PDF：例如从 Word 导出的文件，正文通常以文字对象保存。
- 扫描 PDF：页面主要由扫描图像构成，其中的文字需要通过 OCR 识别。
- 混合 PDF：不同页面使用不同形式，同一页也可能同时包含文字对象、图片、表格和公式。

**文字能否复制只能作为线索。** 扫描件也可能带有可复制的 OCR 文字层；原生 PDF 的文字也可能因字体编码问题复制出乱码。需要结合文字层质量、图像分布和页面渲染结果判断。

一页 PDF 中可能同时存在页眉、页脚、双栏正文、图片、表格和数学公式。LaTeX 是识别后表示数学公式的一种形式；版面分析则负责处理位置、分栏和阅读顺序。

**核心原则：一页可以同时具有文字、图片、表格和公式。页面级分类用于选择总体处理策略，不能代替区域级识别。**

因此，不能只提取 PDF 的文字就直接分块。需要先识别内容、恢复结构与关系，再将结果用于检索。

## 推荐处理流程

1. 检查 PDF 的基础情况。
2. 逐页分析文字层、图像分布和版面。
3. 根据页面及区域情况，选择文字提取、OCR 或视觉解析。
4. 恢复阅读顺序，建立结构化内容及关系。
5. 检查解析质量，对低质量页面或区域进行必要的回退重试。
6. 保护有效信息，再执行内容清洗。
7. 按内容结构和关联关系分块。
8. 进行嵌入与索引。

旋转校正、去倾斜等图像预处理应在识别前按需执行。清洗后也需要检查是否误删内容或破坏结构，质量检查并不限于一个阶段。

## PDF 质量检测和页面分析

### 基础情况

先确认文件和页面能否正常读取，再收集基础信息：

- 文件页数
- 文件大小
- 是否加密
- 是否损坏
- 页面宽高
- 页面旋转角度
- 是否存在文字对象
- 是否存在图片对象

对象存在不代表内容已经可用：文字层可能乱码或缺失，图片对象也不能直接说明里面是照片、截图、表格还是公式。

### 逐页分析，再按区域选择处理方式

每一页都需要单独分析，因为前几页可能是封面、目录，而后续页面的内容形式可能完全不同。一页可能是正文加图片，另一页可能是正文加表格截图。

页面分析需要判断文字层是否可用、图像如何分布、页面是否分栏，以及哪些区域需要额外识别。同一页中的正文可以直接提取，截图、表格图像或公式区域则可以进入相应的识别流程。

### 建立结构化内容与关系

结构化结果既要记录“有什么内容”，也要记录这些内容之间的关系。有些段落解读图片，有些段落说明下面的表格；脚注也可能限定正文的适用范围。

每个内容块应能够记录：

- 内容标识和类型，例如正文、标题、图片、表格、公式或脚注。
- 所在页码、原始位置和阅读顺序。
- 原文、原图及对应的识别结果。
- 与图注、说明段落、表头或脚注的关联关系。
- 解析来源和质量信息，便于检查及重试。

这些是推荐保留的信息，并不表示两个项目当前都已完整实现。

### 保留图片等内容的原始位置

如果 PDF 原来的阅读顺序是“正文 A → 图 A → 正文 B”，结构化结果也应保留这个顺序，以及图片与相关正文的关系。

图片提取或 OCR 成功，并不代表已经恢复了插入位置。不能把所有图片移到正文最后后，就认为图文关系已经保留；需要用内容标识、页码、坐标和阅读顺序进行锚定。

### 保护重要的页眉页脚

纯页码、装饰性内容和已经确认无信息价值的重复模板，可以从检索正文中清除。页码仍应保留为来源信息，方便引用和核对。

适用范围、例外条件、版本、生效日期等有效信息需要保留，并关联其作用范围。重复出现只能作为噪声判断的线索，不能单独作为删除依据；无法可靠判断时，应先保留。

### 质量评分与回退重试

程序解析成功，只说明处理没有报错，不代表结果正确。例如，原图中的 `Agent Runtime Model` 被识别成 `Agent Runtime M0del`，字符 `o` 被替换成数字 `0`，就是内容错误。

质量检查应同时关注：

- 文字是否缺失、乱码或存在可疑字符。
- 双栏、段落和图文的阅读顺序是否合理。
- 表格行列关系、公式结构和图片内容是否保留。
- 图注、脚注及相关正文的关联是否完整。
- 清洗是否误删有效信息。

质量评分可以发现部分风险，但不能保证检测出每一个错字。`O/0`、`l/1` 等歧义有时需要对照原图、领域词汇或多个识别结果确认，不能仅凭模型推测修改。

对于低质量页面或区域，可以更换 OCR、结构化解析器或视觉模型重新处理，并使用一致的质量指标比较结果。更强的模型也不能保证识别正确；重试时应保留原始内容、识别版本和来源，便于追溯。

本篇确定页面判断与质量检查的总体原则。具体的图片、表格、公式、阅读顺序、页眉页脚、去重和分块处理，分别在后续笔记中讨论。
