
**DevCLI｜Coding Agent**　[GitHub](https://github.com/shawns-yao/DevCLI)　　　　　　　　　　　　　　　　　**2026.04–至今**  
**项目描述：** 自主研发面向真实代码仓库的 Java Coding Agent，通过可控工具执行与按需多 Agent 协作完成多轮编码任务，并支持长上下文及跨会话状态治理。  
**技术栈：** Java 17｜ReAct｜Multi-Agent｜MCP｜Tool Calling｜Context Engineering｜Agent Memory｜Docker

- **Agent Runtime 与任务分派：** 基于 ReAct 实现统一执行内核与结构化 Tool Calling，将复杂任务按需分派至隔离子 Agent，并统一控制执行预算与取消传播；在 SWE-bench Multilingual Java 测试任务解决率达到 **65.1%**，较单 Agent 提升 **9.3 个百分点**。
    
- **工具治理与安全执行：** 针对 Tool Calling 中的越权访问、非法参数及并发写冲突，构建由副作用分级、Schema 校验、HITL 审批和版本闸门组成的确定性执行链路；在 **AgentDojo 上 Benign Utility 达到 **82.5%**，Targeted ASR 从 **18.7%** 降至 **4.8%**。
    
- **长上下文治理：** 针对长任务中 Tool Output 膨胀、摘要失真及关键事实丢失，设计分层压缩链路，以异步预摘要降低主链路阻塞，并通过结构化摘要与关键事实校验保持任务连续性；在 **LongBench 英文 QA 1,150 个样本**上QA F 1 由 **71.4** 降至 **68.7**，保留 **96.2%** 的任务质量。
    
- **分层 Agent Memory：** 分离任务运行态与跨会话稳定事实，按全局/项目作用域治理记忆，并通过有效期、版本修订和来源证据抑制过期或冲突信息，实现跨会话知识复用；在 **LongMemEval-S Cleaned 500 个样本**上 QA Accuracy 达到 **87.2%**。
