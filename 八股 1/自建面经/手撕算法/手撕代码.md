# 1.1 找出最长的字符子串。

<div style="--primary:#3A5FBF;--card:var(--background-primary);--border:var(--background-modifier-border);--text:var(--text-normal);--muted:var(--text-muted);max-width:780px;font:14px/1.65 Roboto,'PingFang SC','Segoe UI',Arial,sans-serif;color:var(--text);margin:12px 0;box-sizing:border-box;">
  <span style="display:inline-block;padding:2px 10px;border-radius:999px;background:rgba(58,95,191,.10);border:1px solid rgba(58,95,191,.22);color:#3A5FBF;font-size:12.5px;font-weight:600;">公司：蔚来</span>
  <div style="margin:8px 0 0;background:var(--card);border:1px solid var(--border);border-left:3px solid var(--primary);border-radius:12px;padding:12px 14px;">
    <b>回答：</b>
    <div style="margin:6px 0 0;">通常这道题指“最长无重复字符子串”。可以使用滑动窗口和哈希表：右指针不断向右扩展，记录每个字符最近一次出现的位置；如果当前字符在窗口内重复，就把左指针移动到重复字符上次位置加一。每次扩展后更新最大长度。</div>
  </div>
</div>

Java 写法如下：

```java
public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> last = new HashMap<>();
    int left = 0;
    int answer = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (last.containsKey(c)) {
            left = Math.max(left, last.get(c) + 1);
        }
        last.put(c, right);
        answer = Math.max(answer, right - left + 1);
    }
    return answer;
}
```

  <div style="margin:8px 0 0;background:var(--card);border:1px solid var(--border);border-left:3px solid var(--primary);border-radius:12px;padding:12px 14px;">
    <div style="margin:0;">时间复杂度是 <code>O(n)</code>，空间复杂度是 <code>O(k)</code>，其中 <code>k</code> 是字符集大小。关键是左指针只能向右移动，不能因为重复字符把窗口左边界移回去。</div>
  </div>
</div>

# 1.20 反转链表 / 每 m 个反转 / 隔 K 反转怎么做？

<span style="display:inline-block;padding:2px 10px;border-radius:999px;background:rgba(58,95,191,.10);border:1px solid rgba(58,95,191,.22);color:#3A5FBF;font-size:12.5px;font-weight:600;">公司：字节、腾讯、懂车帝</span>

<div style="--primary:#3A5FBF;--card:var(--background-primary);--border:var(--background-modifier-border);--text:var(--text-normal);--muted:var(--text-muted);max-width:780px;font:14px/1.65 Roboto,'PingFang SC','Segoe UI',Arial,sans-serif;color:var(--text);margin:12px 0;box-sizing:border-box;">
  <div style="margin:8px 0 0;background:var(--card);border:1px solid var(--border);border-left:3px solid var(--primary);border-radius:12px;padding:12px 14px;">
    <b>思路：</b>
    <div style="margin:6px 0 0;"><b style="color:#3A5FBF;">① 整体反转（三指针）：</b><code>prev → cur → next</code> 迭代，每次让 <code>cur.next = prev</code> 后整体右移，最后返回 prev。核心代码：<code>while (cur != null) { next = cur.next; cur.next = prev; prev = cur; cur = next; }</code>。</div>
    <div style="margin:8px 0 0;"><b style="color:#3F8C12;">② 每 K 个一组反转（分组反转）：</b>先数剩余节点是否够 K（不足则不动）；够则用三指针反转本组 [start, end]，<b>反转后接回前后</b>：用 <code>dummy</code> 哑节点 + <code>pre</code> 指向组前，组反转后 <code>pre.next = newHead</code>，组尾 <code>next</code> 续到下一组；每 m 个反转 = K=m；隔 K 反转（LeetCode 25）剩余不足 K 保持原序。</div>
    <div style="margin:8px 0 0;"><b style="color:#3A5FBF;">复杂度：</b>时间 O(n)（每个节点访问常数次），空间 O(1)（迭代）或 O(n/k)（递归分组）。</div>
    <div style="margin:8px 0 0;"><b style="color:#B26E00;">追问：</b>递归反转怎么写（先反后面再处理当前节点）；反转区间 [left, right]（LeetCode 92：先走到 left 前，组内反转接回）；为什么需要 dummy 节点（头节点可能被换掉）。</div>
  </div>
</div>

# 1.21 二叉树子结构 / 最近公共祖先（LCA）怎么做？

<span style="display:inline-block;padding:2px 10px;border-radius:999px;background:rgba(58,95,191,.10);border:1px solid rgba(58,95,191,.22);color:#3A5FBF;font-size:12.5px;font-weight:600;">公司：字节、快手</span>

<div style="--primary:#3A5FBF;--card:var(--background-primary);--border:var(--background-modifier-border);--text:var(--text-normal);--muted:var(--text-muted);max-width:780px;font:14px/1.65 Roboto,'PingFang SC','Segoe UI',Arial,sans-serif;color:var(--text);margin:12px 0;box-sizing:border-box;">
  <div style="margin:8px 0 0;background:var(--card);border:1px solid var(--border);border-left:3px solid var(--primary);border-radius:12px;padding:12px 14px;">
    <b>思路：</b>
    <div style="margin:6px 0 0;"><b style="color:#3A5FBF;">① LCA（递归）：</b>后序遍历：当前节点为 null 返回 null；等于 p 或 q 返回自身；否则递归左右子树——左、右都非空说明当前节点就是 LCA；只有一侧非空返回那侧。核心：<code>if (left != null && right != null) return root; return left != null ? left : right;</code>。</div>
    <div style="margin:8px 0 0;"><b style="color:#3F8C12;">② 子结构匹配（剑指 26）：</b>两层递归——外层：遍历 A 每个节点找与 B 根值相同的起点（<code>isSubStructure(A, B) = match(A, B) || isSubStructure(A.left, B) || isSubStructure(A.right, B)</code>）；内层 <code>match(a, b)</code>：b 为空返回 true（B 已匹配完），a 为空返回 false，值不等返回 false，否则递归匹配左右。</div>
    <div style="margin:8px 0 0;"><b style="color:#3A5FBF;">复杂度：</b>LCA 时间 O(n)、空间 O(h)；子结构最坏 O(n·m)（每节点尝试匹配）。</div>
    <div style="margin:8px 0 0;"><b style="color:#B26E00;">追问：</b>LCA 用父指针怎么做（先记录路径再找交点）；p/q 不存在时 LCA 返回什么（区分「找到」与「不存在」，用标志位）；二叉搜索树 LCA 怎么优化（按值大小走向）。</div>
  </div>
</div>

# 1.24 蓄水池抽样是什么？怎么实现？

<span style="display:inline-block;padding:2px 10px;border-radius:999px;background:rgba(58,95,191,.10);border:1px solid rgba(58,95,191,.22);color:#3A5FBF;font-size:12.5px;font-weight:600;">公司：拼多多</span>

<div style="--primary:#3A5FBF;--card:var(--background-primary);--border:var(--background-modifier-border);--text:var(--text-normal);--muted:var(--text-muted);max-width:780px;font:14px/1.65 Roboto,'PingFang SC','Segoe UI',Arial,sans-serif;color:var(--text);margin:12px 0;box-sizing:border-box;">
  <div style="margin:8px 0 0;background:var(--card);border:1px solid var(--border);border-left:3px solid var(--primary);border-radius:12px;padding:12px 14px;">
    <b>思路：</b>
    <div style="margin:6px 0 0;"><b style="color:#3A5FBF;">概念原理：</b>在<b>数据流长度未知</b>（或太大不能全存）时等概率随机抽取 K 个样本。核心性质：第 i 个元素以 K/i 的概率替换池中随机一个元素，最终每个元素被选中的概率都是 K/N。</div>
    <div style="margin:8px 0 0;"><b style="color:#3F8C12;">实现（K=1）：</b>维护候选 <code>res</code>；读到第 i 个元素时，以 <b>1/i</b> 概率用新元素替换 res（<code>if (rand.nextInt(i) == 0) res = num</code>）；流结束后 res 即等概率抽样结果。</div>
    <div style="margin:8px 0 0;"><b style="color:#3A5FBF;">复杂度：</b>时间 O(N)（只遍历一次）、空间 O(K)。</div>
    <div style="margin:8px 0 0;"><b style="color:#B26E00;">追问：</b>为什么是 1/i（第 i 个被选中的概率 = 选中且后续不被替换 = 1/i × Π(1-1/j) = 1/N）；抽样 K 个怎么改（池 + 第 i 个以 K/i 概率替换池中随机一个）；应用场景（大数据随机采样、负载均衡随机选一台）。</div>

<div style="--primary:#3A5FBF;--card:var(--background-primary);--border:var(--background-modifier-border);--text:var(--text-normal);--muted:var(--text-muted);max-width:780px;font:14px/1.65 Roboto,'PingFang SC','Segoe UI',Arial,sans-serif;color:var(--text);margin:12px 0;box-sizing:border-box;">

  <div style="margin:8px 0 0;background:var(--card);border:1px solid var(--border);border-left:3px solid var(--primary);border-radius:12px;padding:12px 14px;">
    <b>思路：</b>
    <div style="margin:6px 0 0;"><b style="color:#3A5FBF;">概念原理：</b>核心思想是<b>分而治之 + 外存换内存</b>：单机内存装不下就用哈希分片拆小，小文件可进内存后再合并。三大经典场景：</div>
    <div style="margin:8px 0 0;"><b style="color:#3F8C12;">① 超大文件 TopK / 频次统计：</b>哈希分片——按 <code>hash(key) % N</code> 把数据分散到 N 个小文件，每块内存统计（HashMap/堆），最后合并各块结果（多路归并或再堆）；适用：100G 日志统计 TopK IP、热词。</div>
    <div style="margin:8px 0 0;"><b style="color:#3F8C12;">② 外部排序：</b>内存放不下时：分块读入排序写回（每块已序）→ 多路归并（K 路败者树/堆）合并成整体有序；归并轮数 = log(块数)。</div>
    <div style="margin:8px 0 0;"><b style="color:#3F8C12;">③ 大文件去重：</b>布隆过滤器预判（可能误判）→ 哈希分片后精确 Set 去重；或直接分片 + 每片 HashSet。</div>
    <div style="margin:8px 0 0;"><b style="color:#3A5FBF;">复杂度与要点：</b>总复杂度 ≈ O(N) 分片 + 各块处理 + 归并 O(N·log(块数))；分片数按内存预算定（每块能进内存）；hash 要均匀；流式读取（buffered）避免整读。</div>
    <div style="margin:8px 0 0;"><b style="color:#B26E00;">追问：</b>两个超大文件找交集（分别哈希分片后对应块求交集）；数据分布不均（hash 倾斜）怎么办（二次分片/热点单独处理）；分布式怎么做（MapReduce 思想：map 分片 → reduce 归并）。</div>
