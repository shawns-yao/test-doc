# 01 如何在 Agent 岗位面试中提出有效反问

## 01 核心回答

反问其实是变相考察你对这个方向的思考深度,参考几个方向:

团队现在 Agent 相关项目主要用的什么技术栈,是基于开源框架二次开发还是自研?

团队 Agent 项目现在处于什么阶段,是还在打磨 demo,还是已经在生产环境跑量了?

平时怎么评估和监控 Agent 的效果,有没有专门的评测/回归体系?

这个岗位日常更偏算法调优(Prompt、模型选型),还是偏工程落地(稳定性、成本、可观测性)?

---

## 02 优先问能改变岗位判断的问题

时间有限时选两三个最关心的问题：目前最常见的真实任务、衡量成功的标准、这个岗位拥有的实现与上线职责。先接住面试中已经提到的信息，避免重复问对方刚解释过的技术栈。

对 Agent 可以追问一个失败案例如何进入评测集、工具执行何时需要审批、延迟和成本预算怎么取舍。只问公开或适合面试交流的流程，不要求展示客户数据、内部凭据或保密方案。

---

## 03 把答案转成后续判断

听清是已有生产实践、正在建设还是规划，再对照自己的目标；框架自研与否本身不直接证明技术深度。若对方给出泛泛回答，可请其用一个经过脱敏的典型任务说明，而不是连续抛出更多名词。
