# 06 规则知识库和 embedding memory 的差别？

## 01 核心回答

**回答（硬规则 vs 软记忆）：**

**规则库：**稳定、可审计、可追责——适合合规/风控边界、权限、计费、交易限制。

**embedding：**覆盖广、能处理长尾，但可能召回偏差——适合 FAQ、经验复用、个性化上下文、知识问答。

工程实践：经审核的规则由确定性执行器实施硬约束，规则文档本身不保证执行，embedding 做「语义检索和补充上下文」。

---

## 02 “规则”与“检索”不是同一分类维度

自然语言规则文档可以通过 embedding 检索，但检索到一段规则并不会自动强制执行。硬约束必须转成经审核的策略配置或确定性代码，并由执行器应用；规则库中只是存着文本，不能声称已具备最终裁决能力。

语义记忆负责找可能相关的历史事实或经验，允许近似；权限、额度、计费等需精确匹配当前主体、资源和版本，不能用相似度最高的一条决定。规则版本与生效时间要明确，冲突规则需有优先级与审批流程。

## 03 组合例子与口述

可改编例子：检索到处理退款的历史案例帮助解释流程，但是否可退款、金额上限和审批人由当前业务规则校验。旧案例不应覆盖新政策。

追问“向量库能否存规则？”能作为检索索引，不能替代执行规则。口述：“规则决定必须遵守的边界，语义记忆提供相关上下文，最终动作仍通过当前策略检查。”
