# 24 怎么降低「假引用」和幻觉？

## 01 核心回答

**回答（四层系统控制，不依赖 prompt 小技巧）：**

① **数据源控制**——只允许白名单源进入关键链路（PubMed、官方指南、临床试验注册库、专利库）；② **生成前约束**——先抽证据再生成，要求引用 ID 先被检索系统验证；③ **生成后校验**——检查引用是否存在、标题是否匹配、结论能否被原文支撑；④ **结果展示约束**——把「事实」和「模型推断」分开展示，不确定内容明确标注。

医疗场景增强：多 Agent 协作验证——Writer 生成后 Critic 辅助核对文献，专业证据评价与临床结论仍需合格人员审阅；RAG（实时抓 PubMed）+ Tool Calling（调用真实数据库）+ 有预算的缺陷复核循环；幻觉指标需定义口径、样本与上线阈值，不能给未经验证的固定承诺，Human + Automated Eval 双重把关。

**本质：**降低幻觉是系统设计问题，不是 prompt 小技巧。

---

## 02 两种引用错误分别检查

第一类是不存在或信息不匹配：检查来源 ID、标题、作者、年份和可访问页面；第二类是真文献不支持这句话：检查引用范围、研究对象、数值与方向。只验证 DOI 存在会漏掉第二类。

先从受授权材料构建来源记录，生成只能选择已存在 ID；后处理逐断言核对证据支持，数值尽量从结构化字段直接提取。遇到撤稿、更正、版本变化或只读到摘要时要显示限制。白名单降低来源风险，但白名单里的材料也可能过期或存在错误。

---

## 03 评价与边界

原文“反思 3 次”“幻觉率 <1%”是未经实验支持的示例，不是通用保证；必须说明何为幻觉、按断言还是答案计数、样本量和置信区间。GRADE 等专业评价方法需要适当证据与专业判断，不能仅靠一个 Critic 角色自动完成。

口述：“引用真实、引用支持、内容正确是三个检查层，模型自检有帮助但不能替代原文核验与专业审阅。”
