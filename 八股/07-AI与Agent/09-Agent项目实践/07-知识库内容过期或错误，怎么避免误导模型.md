# 07 知识库内容过期或错误，怎么避免误导模型？

## 01 核心回答

**回答（三层 + 止损）：**

**① 入库：**所有知识带**版本号、生效/失效时间、来源等级和责任人**，过期内容自动降权或下线；费率、风控、政策等高危知识人工审核后才能进高可信索引。

**② 检索：**先做 **metadata 硬过滤**（只查有效时间、可信来源），再做向量 + 关键词混检和重排序，把相似度、新鲜度、可信度一起打分，避免旧文档因语义相近被误召回。

**③ 生成：**要求模型「有证据才回答」必须带引用；证据不足或冲突时直接拒答或提示人工确认。

**④ 线上止损：**快速封禁问题文档 ID/来源；持续监控过期命中率、引用覆盖率、冲突率、幻觉率，指标异常一键切高可信索引并回滚快照。

---

## 02 新鲜度不等于可信度

新发布内容也可能错误，旧规范在有效期内仍可能权威。分别存发布时间、业务生效时间、失效时间、来源和审核状态；查询按所问时间定位适用版本，历史问题不能一律过滤成最新版。

错知识一旦进入缓存、摘要或长期记忆，仅封禁原文 ID 可能不够。建立来源到派生结果依赖，失效相关答案缓存、索引和记忆；权限撤回同样要优先阻断。版本回滚前检查删除与授权事实，避免恢复不该再可见的内容。

---

## 03 追问与口述

“证据冲突怎么办？”展示适用时间和来源差异，必要时由负责人核验，不能投票决定政策。“怎么量化？”测过期引用率、索引滞后和纠错传播时长，配带历史时间条件的回归样本。

口述：“把有效性、可信度与版本分开管理，让纠错沿整个派生链传播。”相关：[[八股/08-RAG与MCP/01-RAG检索增强/10-RAG 生产环境的挑战与治理|RAG 一致性治理]]。
