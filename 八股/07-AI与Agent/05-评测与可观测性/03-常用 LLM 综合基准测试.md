# 03 常用 LLM 综合基准测试？

## 01 核心回答

**能力覆盖：****MMLU**考察多学科知识与选择题推理，**BIG-Bench**覆盖大量任务和泛化能力，**GSM8K**偏小学数学推理，**HumanEval**评估代码生成并常用 `pass@k`，还可根据需要加入 TruthfulQA、GPQA、MMMU 等事实、专业和多模态测试。

**使用边界：**不同基准的数据污染、题型格式和语言分布会影响排名；单一分数不能代表生产能力，也不能直接推断 Agent 的工具调用、长链路稳定性和业务成本。

**工程做法：**公开基准用于横向了解能力，业务黄金集用于纵向版本回归，再补充延迟、Token 成本、失败率和安全测试。固定数据版本、提示词、采样参数和评分脚本，保证结果可复现。

---

## 02 使用基准的注意点

pass@k 表示生成 k 个候选中至少一个通过测试的概率估计，不能直接当作一次调用成功率；要报告采样数、温度、预算和测试环境。GSM8K 或 HumanEval 的表现也不能直接代表真实复杂工程任务。

公开测试可能存在训练污染，模型或提示在测试集上反复调参也会造成过拟合。将公开基准作为能力参考，业务保留未见测试集与时间外样本，避免只追排行榜。

口述：“我会说明测的能力、使用版本和预算，再展示与业务任务的相关性，不用一个总分决定上线。”
