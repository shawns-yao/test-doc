# 07 Agent 能力基准测试有哪些？

## 01 核心回答

① **WebArena**——网页浏览与操作（电商/论坛/写作工具环境，程序化判断终态）；② **AgentBench**——通用 Agent 综合评估（OS 终端、SQL 数据库、知识图谱、文字冒险等八种环境）；③ **GAIA**——模拟人类用真实工具完成复杂任务（网页搜索 + 代码 + 文件操作并用）。

**环境构建：**可控隔离沙箱（Docker 封装浏览器/终端/文件系统），任务以**高层次目标**给出（不给具体步骤），附带可程序化验证的成功标准——评估规划、工具使用和鲁棒性，而不仅是最终文本质量。

---

## 02 基准之间不能直接换算

WebArena 关注网页任务的功能性终态；AgentBench 汇集多类交互环境；GAIA 主要以有确定答案的真实世界助理问题考察工具与推理能力。它们的任务环境、工具预算与成功判据不同，排名不能视作统一 Agent IQ。

生产测试需固定环境和数据快照，避免上次运行留下订单或文件改变下次结果。对写动作使用隔离账户和可重置数据，测试终态之外还检查非目标资源是否被误改。

追问“公开分数高为什么项目仍失败？”业务权限、私有知识、真实依赖抖动与任务分布可能没有被该基准覆盖。
