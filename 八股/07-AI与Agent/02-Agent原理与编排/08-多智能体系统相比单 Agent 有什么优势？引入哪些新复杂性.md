# 08 多智能体系统相比单 Agent 有什么优势？引入哪些新复杂性？

## 01 核心回答

多智能体系统就是把一个复杂目标拆成多个角色协同完成（规划、执行、审校分工），可能提高复杂任务成功率，需要对照验证。优势：① **专业化**——每个 Agent 设定不同角色和专长，可基于专门知识和工具微调；② **并行化**——复杂任务分解后分配给不同 Agent 同时处理，缩短总时间。

**新增复杂性：**① **通信协议**——Agent 之间如何有效沟通，需要标准化的消息格式确保相互理解意图、状态和知识；② **任务协调、状态一致性**——谁负责、谁失败、谁回滚都要定义清楚，没有明确编排规则时多 Agent 反而比单 Agent 更不稳定。常用框架：LangGraph、OpenAI Agents SDK、AutoGen、CrewAI。

---

## 02 为什么多 Agent 也会更差

拆分后会损失共享上下文，结果交接可能遗漏约束；多个模型还可能共享同一错误知识，投票一致不等于正确。只有可并行、可独立评价、任务边界明确时，分工收益才容易兑现。

工程上为每个子任务定义 owner、依赖、输入引用、产物版本、验收条件和超时；共享可变状态尽量单写者管理。专家失败时由主控决定重试、替换或部分交付，不能让两个角色互相等待或递归派活。

口述：“多 Agent 是可选的分解与隔离手段，我会比较同预算的单 Agent 基线，再用交接错误率和总成本判断值不值得拆。”
