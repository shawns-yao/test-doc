# 01 Agent 的定义与核心组件？软件 Agent 与具身 Agent 有何不同？

## 01 核心回答

**定义与组件：**本文的 LLM Agent 是「以 LLM 为决策中枢、可在环境中闭环执行任务的系统」，通常由四层构成：**规划层、记忆层、工具层和执行控制层**。和普通对话模型相比，关键差异是它能**持续感知、决策、行动并根据反馈修正**。

软件 Agent vs 具身 Agent：具身智能体（Embodied Agent）通过身体或模拟身体感知与作用于环境，强调感知—动作约束；并非所有游戏软件代理都属于具身智能。核心区别是「感知与行动的不确定性」——软件 Agent 可能处理结构化接口，也可能面对动态网页等不确定环境；具身 Agent 面对高维噪声输入、部分可观测状态和连续动作误差，需要实时闭环。更关键的是安全后果：软件动作也可能不可逆，物理动作可能不可逆。

**评估标准变化：**从「答对」升级为「**安全、稳定、可恢复**」，系统设计重点从回答质量转为安全与工程兜底。

**口述重点：**真正拉开差距的是工程控制面——状态管理、异常恢复和可观测性。

---

## 02 勘误与边界

本题主要讨论 LLM Agent。广义 Agent 不必使用 LLM，也可由规则、规划器或强化学习策略驱动。具身性强调有身体及其感知—动作约束，不能把所有游戏中的软件代理都自动称为具身 Agent。软件侧同样可能面对不确定网页和不可逆支付、泄密；“软件错误多数可回滚”不能作为安全假设。

直觉上，Chatbot 可以只给建议，Agent 会读取环境状态并执行可改变环境的动作。是否真的完成，必须由外部结果核验，而不是模型自己说完成。

追问“是否一定要四层？”四层是便于讨论的工程分解，不是定义要求。口述可先给闭环，再用[[八股/07-AI与Agent/02-Agent原理与编排/12-Agent 工具调用的完整业务流程|一次工具调用]]解释每层职责。
