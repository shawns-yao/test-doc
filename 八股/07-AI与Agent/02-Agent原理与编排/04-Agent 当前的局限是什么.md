# 04 Agent 当前的局限是什么？

## 01 核心回答

短板主要是「**稳定性、可控性、成本**」三件事：① **稳定性**——任务链路长、依赖外部工具多，任何一环抖动都会影响成功率；② **可控性**——模型是概率系统，复杂场景下会出现误判、过度调用工具甚至越权风险；③ **成本**——多轮推理 + 检索 + 工具调用叠加，token 和外部 API 成本上升很快。

**产品化挑战：**很多场景还没跨过「可用到可靠」的工程门槛。Agent 更适合**流程明确、容错可设计、收益可量化**的场景（内容生产、客服分流、内部效率工具）。

**做亮点的关键：**不是堆模型，而是**做强编排、评测和治理**，把失败率和成本打下来。

---

## 02 修正产品判断与可靠性分析

“为什么没爆款”是缺乏时间和市场范围的主观判断，不能作为技术结论。更可验证的问题是：在目标场景下，成功率、用户接管成本和单次收益能否覆盖系统成本。

长链路会累积错误，但不能无条件把每步成功率相乘：步骤往往相关，恢复与重试也改变结果。应从真实任务轨迹统计端到端成功率，并分别测错误识别率和恢复成功率。

口述：“当前难点主要是复杂环境中的可靠执行和可控成本。限定任务、验证动作、提供接管能降低风险，但不能声称完全消除幻觉或越权。”
