# 04 Agent 的"记忆"分哪几种?短期记忆和长期记忆分别怎么落地?

## 01 核心回答

**一句话结论:**按时间分**短期(工作)记忆与长期记忆**;按内容分**情景记忆、语义记忆、程序记忆**。

短期记忆落地:包括当前会话/任务状态，本轮可见部分位于上下文窗口。靠 token 预算管理:超限做摘要压缩(Summarization)、滑动窗口只留最近轮次、必要时剔除无关检索片段。

**长期记忆落地:**向量数据库(Embedding 存储历史对话/知识库片段,按相关性检索召回)+ 结构化记忆(用户画像/事实存 KV 或图谱)+ 记忆写入策略(重要信息抽取后入库,避免全量存)。

**追问点:**何时写入记忆?如何更新与遗忘?检索结果与当前上下文怎么融合排序?多用户记忆如何隔离?

记忆要点:短期=任务状态与选入上下文的信息(持久化及摘要/裁剪),长期=跨任务事实与经验(存储方式按访问模式选择)(靠写入/检索策略),再补一句"记忆与检索是两件事,写不进去就检不出来"。

## 02 生命周期和物理介质分开

短期记忆不只等于本轮上下文窗口，还包括会话/任务状态；关键状态需要持久保存，模型每轮只看到其中被选入的片段。长期记忆可用结构化记录或文件，向量索引只是语义访问方式。

写入先核实来源、可复用性和权限；纠错更新源记录及派生索引，遗忘要清理摘要和缓存。情景、语义、程序记忆是另一条内容分类轴，可以与短期/长期交叉，不是互斥的一棵分类树。

口述：“先按用途与保留期定义记忆，再选存储和检索，更新删除与写入同样重要。”参见[[八股/07-AI与Agent/02-Agent原理与编排/22-记忆具体存储在哪里|存在哪里]]。
