# 01 Agent 和普通 Chatbot、和传统 RPA 的本质区别是什么?

## 01 核心回答

**一句话结论:**Chatbot 是被动应答、RPA 是固定规则脚本、Agent 是**目标驱动的自主感知-决策-行动闭环**。

Chatbot:主要描述对话交互形态，可包含多轮、检索和工具；若不自主控制执行流程，常以问答为主。

RPA:按预定义规则与流程执行重复操作(模拟鼠标键盘/调接口),通常按预定规则执行，对未覆盖变化需要补规则或结合 AI。

**Agent:**围绕用户目标,自行规划步骤 → 记忆上下文 → 选择并调用工具 → 观察结果反馈 → 迭代修正直到完成,能在开放、动态环境里自主决策。

记忆要点:能拆目标、会调工具、看得懂结果、错了会重来 = Agent;只会答 = Chatbot;只会照脚本 = RPA。

---

## 02 不把产品名称当严格能力边界

Chatbot 描述对话交互形态，可以是多轮、带检索和工具；RPA 描述流程自动化，也可能结合 AI。因此不能以“有没有聊天界面”或“有没有调一次工具”单独判断 Agent。更清楚的比较维度是：谁决定下一步、如何使用环境反馈、执行范围是否动态。

可改编例子：固定脚本按预设页面顺序抓报表偏 RPA；系统根据报错选择新的查询并验证目标进度，更体现 Agent 式决策。二者都需要权限与验收，自治越高不代表质量越好。

口述：“这些系统可以融合，我会按控制权和反馈闭环解释差异，而不是宣称 Chatbot 天生不会用工具。”相关：[[八股/07-AI与Agent/02-Agent原理与编排/01-Agent 的定义与核心组件？软件 Agent 与具身 Agent 有何不同|Agent 定义]]。
