# 02 怎么评估一个 Agent 做得好不好,有哪些具体指标?

## 01 核心回答

**一句话结论:**不要只看"效果好不好",要分层看 **任务成功率、过程合理性、输出质量、成本效率**,并配离线评测集与线上回评。

**任务层:**任务完成率/成功率、端到端目标达成率(有没有把活干完、干对)。

**过程层:**路径合理性(步数是否绕远、工具调用次数)、重复调用率、无效调用率、死循环率(有没有瞎折腾)。

**质量层:**工具调用准确率、幻觉/瞎调用比例、回答正确率(人工评估 + LLM-as-Judge 自动打分结合)。

**效率层:**单任务 Token 成本、响应延迟(P50/P95)、资源占用。

**评测体系:**离线评测集(golden set)回归 + 线上灰度对比 + 用户反馈回流,形成持续优化闭环。

记忆要点:结果对不对(任务层)+ 过程蠢不蠢(路径层)+ 质量稳不稳(幻觉/准确率)+ 贵不贵(成本效率);能说出"离线评测集 + 线上灰度"闭环是加分项(展开见"题目 2")。

---

## 02 指标必须与用户结果对应

先定义任务成功，例如“报告包含规定证据且可打开”，而不是“模型返回 final”；再区分自动成功、人工完成、阻塞和失败。工具成功率高不代表任务成功，少步骤也不代表合理，可能只是漏做验证。

采用固定环境、多次重复和分桶评测，针对高风险失败设单独门槛。裁判模型需要人工校准，用户满意度是重要反馈但不是事实真值。

口述：“以可验证业务结果为主，以过程、成本和安全解释差异，离线回归与在线反馈共同验证。”见[[八股/07-AI与Agent/05-评测与可观测性/01-如何设计 LLMAgent 评估体系|评价口径]]。
