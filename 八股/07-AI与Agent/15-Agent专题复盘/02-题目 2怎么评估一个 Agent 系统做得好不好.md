# 02 题目 2:怎么评估一个 Agent 系统做得好不好?

## 01 核心回答

**回答思路:**

不要只说"看效果好不好"这种空话,可以从几个维度拆开讲:任务完成率(有没有把活干完)、路径合理性(有没有绕远路、重复调用)、工具调用准确率、幻觉/瞎调用的比例、响应延迟和成本、以及人工评估+自动化评测(比如用另一个模型当裁判打分)结合的方式。

能提一句"离线评测集+线上灰度反馈"闭环会明显加分。

---

## 02 把维度落到一个例子

可改编例子：报告 Agent 的成功条件是覆盖用户问题、关键断言有有效来源、文件可打开且未越权共享。任务完成率用全部进入评测的任务作分母，部分成功和人工完成单列；工具返回 200 不作为最终成功。

过程记录无效检索、重复调用与恢复失败；效率看完整交付 p95 和单位合格报告成本；安全检查无权限资料、提示注入和未经批准的外发。自动裁判按明确 Rubric 评分并与人评校准，不用单一总分抵消严重风险。

口述：“先定义可验收结果，再用过程和成本解释成败，最后用分桶回归验证改动有效。”相关：[[八股/07-AI与Agent/13-Agent生产复习/02-怎么评估一个 Agent 做得好不好,有哪些具体指标|生产指标]]。
