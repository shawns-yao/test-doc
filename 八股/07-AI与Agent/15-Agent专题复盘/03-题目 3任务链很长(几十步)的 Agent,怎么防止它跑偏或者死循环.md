# 03 题目 3:任务链很长(几十步)的 Agent,怎么防止它跑偏或者死循环?

## 01 核心回答

**回答思路:**

可以从几个手段讲:一是设置最大步数/最大工具调用次数硬性上限;

二是引入阶段性检查点,定期让模型回顾目标、判断是否偏离;

三是关键决策点加人工确认或者规则兜底;

四是记忆管理上做摘要压缩,避免上下文塞太满导致模型"忘了自己在干嘛"。

举个自己实际处理过的小例子会比干讲理论更有说服力。

---

## 02 回答时把“防跑偏”和“防死循环”分开

防跑偏靠持续保留目标、授权、未完成条件与证据，并在阶段产物上独立验收；防死循环靠步数/时间/费用硬预算与无进展检测。相同步骤反复没有新证据时改策略或安全停止，不等待预算全部烧完。

进程崩溃后从持久状态恢复，先查外部动作是否已生效；定期自然语言小结不能代替 checkpoint。若原计划被新证据否定，应重规划并记录原因，而不是为了“遵守计划”继续错误方向。

口述示例可用“研究报告某证据缺失导致补检”，但没有实际项目时明确是假设，不制造成功率。相关：[[八股/07-AI与Agent/14-Agent架构复习/02-如果任务要跑几十步才能完成,怎么保证 Agent 不跑偏、不断链|长任务架构]]；[[八股/07-AI与Agent/02-Agent原理与编排/19-当 Agent 遇到无法解决的场景，应该怎么处理|阻塞与停止]]。
