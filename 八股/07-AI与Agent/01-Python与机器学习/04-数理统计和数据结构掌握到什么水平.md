# 04 数理统计和数据结构掌握到什么水平？

## 01 核心回答


**数理统计**

概率分布、期望方差、条件概率、贝叶斯公式、抽样估计、假设检验、置信区间、相关回归——能够理解指标波动和实验结果。

**数据结构与算法**

数组、链表、栈、队列、哈希表、树、堆、图和常见排序查找——能分析时间/空间复杂度，用 Java 或 Python 完成常见题目。

**诚实边界：**不熟的高级算法明确边界并说明学习计划。

**面试追问：**置信区间怎么解释（区间估计而非点估计）；假设检验 p 值含义；哈希冲突怎么解决（链地址/开放寻址）。

---

## 02 易被追问的概念

频率学派 95% 置信区间指重复抽样构造区间的过程约有 95% 覆盖固定参数，不是观测完这个区间后说参数以 95% 概率落在里面。p 值是在零假设及其模型成立时，观测到当前或更极端统计量的概率，不是零假设为真的概率，也不是效果大小。

数据结构可用任务证明掌握程度：去重查找考虑哈希，连续 TopK 考虑堆，依赖调度考虑有向图与拓扑排序；同时说明时间/空间复杂度和最坏情形。口述示例应按真实掌握范围改写，不能把“了解”升级成未经验证的项目熟练度。
