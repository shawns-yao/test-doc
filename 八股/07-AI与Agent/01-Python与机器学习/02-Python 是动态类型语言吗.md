# 02 Python 是动态类型语言吗？

## 01 核心回答


**概念原理：**Python 是**动态类型**语言——变量本身不声明固定类型，类型信息绑定在运行时对象上。同一个变量可以先后指向不同类型的对象（`x = 1` 后再 `x = "1"`，是重新绑定）；函数参数可接收不同类型对象，能否执行取决于运行时对象是否支持相应操作。

**动态类型 ≠ 弱类型：**Python 是**强类型**语言——`1 + "1"` 不会隐式拼接，而是抛 `TypeError`。

**工程实践：**类型注解、`mypy`、IDE 检查和单元测试可提前发现类型问题——但注解主要用于**静态分析**，不会把 Python 变成编译期强制类型。

**风险与取舍：**开发灵活、迭代快，代价是部分错误推迟到运行时——大型项目用类型注解、接口约束、测试和代码评审补足风险。

**面试追问：**动态类型和鸭子类型的区别（运行时行为 vs 接口约定）；mypy 是运行时生效吗（不是，静态分析）；和 Java 的编译期检查差异。

---

## 02 追问中的类型边界

动态类型描述绑定与检查时机，鸭子类型描述按对象支持的行为使用接口，二者不是同义词。类型注解本身不自动做运行时校验；Pydantic 等库会按其规则验证和转换数据，这是库能力。

“强类型”没有统一的严格二分定义，Python 通常这样归类，但仍允许 int 与 float 等数值转换。口述时用具体行为解释比单背“强动态”更可靠。可继续说明：变量重新绑定不会改变原对象的类型；列表对象内容可变也不等于列表变量有静态类型。
