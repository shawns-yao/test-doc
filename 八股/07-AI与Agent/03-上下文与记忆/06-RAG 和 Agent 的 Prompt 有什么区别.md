# 06 RAG 和 Agent 的 Prompt 有什么区别？

## 01 核心回答

**目标差异：**RAG Prompt 核心是「**基于给定证据回答**」——强调引用、边界和事实一致性；Agent Prompt 核心是「**驱动任务执行**」——强调计划、工具选择、状态推进和失败处理。

**结构（六段式）：**角色、任务、上下文、约束、示例、输出格式。RAG 里**上下文段最重**——「仅依据检索片段回答，缺失就明确说不知道」；Agent 里**工具规范最重**——何时调用工具、入参格式、异常分支和停止条件。

与模型交流两点：① 结构化输入输出（JSON Schema）减少歧义；② 把策略写成可观测规则（「最多重试 2 次，超过则降级」）——把提示词变成清晰的运行约定，硬限制由执行器实施，便于调试和复盘。

---

## 02 共同底线与可验证约束

RAG 和 Agent 的 Prompt 可以重合：Agent 也需要基于证据回答，RAG 也可以有多步检索。区别主要在本次目标是证据整合还是动作决策，而不是固定模板数量。

“仅依据材料”应同时配出处映射和证据不足处理；“最多重试两次”要在执行器计数；“需要审批”要绑定具体动作、参数和审批者身份。检索材料与工具返回须标明不可信输入，不能让文档中的指令覆盖用户目标。

直接追问：“把规则写进 Prompt 就算可执行协议吗？”只是模型可读的约定，真正执行仍需程序验证和测试。
