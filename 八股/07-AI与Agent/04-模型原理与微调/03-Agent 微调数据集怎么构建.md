# 03 Agent 微调数据集怎么构建？

## 01 核心回答

Agent 微调不仅学习最终答案，还学习可观察的工具选择、参数、反馈、恢复与停止行为；行为克隆是常见训练方式之一。

数据构造：用真实执行或明确标注的模拟观察构建工具行为轨迹，结合专家示范与教师生成候选进行核验；保留经修正的失败恢复和拒绝示范，不要求获取隐藏思维链。数据来源一般包括：合成任务、真实线上失败案例和专家示范。

**实践：**先做行为克隆打基础，再用偏好数据做策略优化，提升稳定性。

---

## 02 训练轨迹不等于真实思维

优先保存可监督的输入、工具 schema、选中工具、参数、观察、状态和合格输出，以及必要的简短决策理由。教师产生的 Thought 只是生成文本，不能当成真实内部推理，训练不需要依赖获取或披露隐藏思维链。

失败样本不能全部删掉：应保留经标注的纠错、拒绝越权、证据不足澄清与安全停止示范，避免模型只学“永远成功”。工具返回必须来自真实执行或明确标注的模拟器；虚构成功结果会教模型假完成。

数据集按任务、用户或时间隔离，去掉密钥与私人数据，检查许可；离线动作匹配率之外，还需在隔离环境回放端到端结果。
