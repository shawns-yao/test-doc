# 04 LoRA 在 Agent 微调中的应用场景？

## 01 核心回答

LoRA 适合「行为和表达对齐」，不适合「实时知识更新」。Agent 微调常见场景：① **工具调用格式稳定化**——让模型更稳定地产生 JSON/function call；② **角色风格一致化**——客服、投研、写作助手的语气和输出结构；③ **领域术语适配**——金融、法律、医疗等垂类表达更专业；④ **多租户个性化**——每个客户挂不同 LoRA adapter，而不是训多套大模型。

---

## 02 何时值得训练一个适配器

先判断重复失败是否来自稳定的行为模式，例如工具选择、参数格式或领域术语，而不是缺少新资料。Schema 错误可以先通过结构化解码和校验解决，权限问题不能靠 LoRA 解决。

多租户适配器需隔离训练数据、访问权限和路由；错挂 adapter 可能把一家的风格或信息用于另一家。适配器并不能替代数据治理，也不保证不会记忆训练中的敏感信息。

口述：“LoRA 是参数高效适配手段，我会用任务与安全回归证明收益；实时事实查数据源，硬权限留在执行层。”
