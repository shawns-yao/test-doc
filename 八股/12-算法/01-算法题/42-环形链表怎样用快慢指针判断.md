# 42 环形链表怎样用快慢指针判断

沿用ListNode定义；比较节点身份，不比较val。

## 01 Java 核心代码

```java
public static boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}
```

---

## 02 复杂度

- 时间：O(n)，n为不同可达节点数；入环后两指针相对速度为1，至多再走一个环长就相遇
- 空间：O(1)，无递归；初始同在head不作为相遇结果
