# 07 如何求最长递增子序列，并输出对应子序列？

## 01 核心代码

严格递增；输出任意一条最长子序列，不要求字典序最小。

```java
import java.util.*;

static int[] lis(int[] a) {
    int n = a.length, size = 0;
    int[] tail = new int[n], previous = new int[n];
    Arrays.fill(previous, -1);
    for (int i = 0; i < n; i++) {
        int lo = 0, hi = size;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (a[tail[mid]] < a[i]) lo = mid + 1;
            else hi = mid;
        }
        if (lo > 0) previous[i] = tail[lo - 1];
        tail[lo] = i;
        if (lo == size) size++;
    }
    int[] result = new int[size];
    for (int i = size - 1, p = size == 0 ? -1 : tail[size - 1]; i >= 0; i--) {
        result[i] = a[p]; p = previous[p];
    }
    return result;
}
```

---

## 02 时间和空间复杂度

时间 O(n log(n+1))；额外空间 O(n)，含前驱和尾下标；输出空间 O(L)。
