# 48 课程表怎样用入度判断有向图是否有环

先修对[a,b]表示b→a，课程编号0到numCourses−1。

## 01 Java 核心代码

集合与工具类型来自 java.util。

```java
public static boolean canFinish(int numCourses, int[][] prerequisites) {
    List<List<Integer>> next = new ArrayList<>(numCourses);
    for (int i = 0; i < numCourses; i++) next.add(new ArrayList<>());
    int[] indegree = new int[numCourses];
    for (int[] edge : prerequisites) {
        next.get(edge[1]).add(edge[0]);
        indegree[edge[0]]++;
    }
    Deque<Integer> ready = new ArrayDeque<>();
    for (int i = 0; i < numCourses; i++) {
        if (indegree[i] == 0) ready.addLast(i);
    }
    int finished = 0;
    while (!ready.isEmpty()) {
        int course = ready.removeFirst();
        finished++;
        for (int after : next.get(course)) {
            if (--indegree[after] == 0) ready.addLast(after);
        }
    }
    return finished == numCourses;
}
```

## 02 复杂度

- 时间：O(V+E)，每课程入队一次，每先修关系处理一次
- 空间：O(V+E)，含邻接表、入度和队列；无递归
