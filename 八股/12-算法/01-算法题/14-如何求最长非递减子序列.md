# 14 如何求最长非递减子序列？

## 01 核心代码

允许相等，返回最长非递减子序列长度。

```java
import java.util.*;

static int lndsLength(int[] a) {
    int[] tails = new int[a.length];
    int size = 0;
    for (int x : a) {
        int lo = 0, hi = size;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (tails[mid] <= x) lo = mid + 1;
            else hi = mid;
        }
        tails[lo] = x;
        if (lo == size) size++;
    }
    return size;
}
```

## 02 时间和空间复杂度

时间 O(n log(n+1))；空间 O(n)。需要恢复具体序列时，沿用关联 LIS 代码的前驱下标，并把二分比较改为 ≤。
