# 13 如何实现非递归快速排序？

## 01 核心代码

原地、不稳定排序；随机三路分区；显式栈保存较大分段，立即处理较小分段。

```java
import java.util.*;

static void quickSort(int[] a) {
    if (a.length < 2) return;
    Deque<int[]> stack = new ArrayDeque<>();
    stack.push(new int[]{0, a.length - 1});
    while (!stack.isEmpty()) {
        int[] range = stack.pop();
        int lo = range[0], hi = range[1];
        while (lo < hi) {
            int pivot = a[java.util.concurrent.ThreadLocalRandom.current().nextInt(lo, hi + 1)];
            int lt = lo, i = lo, gt = hi;
            while (i <= gt) {
                if (a[i] < pivot) swap(a, lt++, i++);
                else if (a[i] > pivot) swap(a, i, gt--);
                else i++;
            }
            if (lt - lo < hi - gt) {
                if (gt + 1 < hi) stack.push(new int[]{gt + 1, hi});
                hi = lt - 1;
            } else {
                if (lo < lt - 1) stack.push(new int[]{lo, lt - 1});
                lo = gt + 1;
            }
        }
    }
}
static void swap(int[] a, int i, int j) {
    int t = a[i]; a[i] = a[j]; a[j] = t;
}
```

---

## 02 时间和空间复杂度

期望时间 O(n log n)，最坏 O(n²)；显式栈额外空间 O(log n)。
