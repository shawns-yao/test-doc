# 05 如何求两个有序数组的中位数？

## 01 核心代码

两个数组均非递减；至少一个非空；不修改输入。

```java
import java.util.*;

static double median(int[] a, int[] b) {
    if (a.length > b.length) return median(b, a);
    int m = a.length, n = b.length;
    if (m == 0 && n == 0) throw new IllegalArgumentException();
    int lo = 0, hi = m, half = (int)(((long)m + n + 1) / 2);
    while (lo <= hi) {
        int i = lo + (hi - lo) / 2, j = half - i;
        int al = i == 0 ? Integer.MIN_VALUE : a[i - 1];
        int ar = i == m ? Integer.MAX_VALUE : a[i];
        int bl = j == 0 ? Integer.MIN_VALUE : b[j - 1];
        int br = j == n ? Integer.MAX_VALUE : b[j];
        if (al > br) hi = i - 1;
        else if (bl > ar) lo = i + 1;
        else if ((((long)m + n) & 1) == 1) return Math.max(al, bl);
        else return ((long)Math.max(al, bl) + Math.min(ar, br)) / 2.0;
    }
    throw new IllegalArgumentException("arrays must be sorted");
}
```

---

## 02 时间和空间复杂度

时间 O(log(min(m,n)+1))；额外空间 O(1)。
