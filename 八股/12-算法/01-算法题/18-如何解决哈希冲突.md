# 18 如何解决哈希冲突？

## 01 核心代码

用链地址法演示冲突处理；固定 B 个桶，int 键值，不自动扩容。

```java
import java.util.*;

static class ChainedMap {
    static class Node {
        int key, value; Node next;
        Node(int key, int value, Node next) { this.key=key; this.value=value; this.next=next; }
    }
    final Node[] buckets;
    ChainedMap(int capacity) {
        if (capacity <= 0) throw new IllegalArgumentException();
        buckets = new Node[capacity];
    }
    int bucket(int key) { return Math.floorMod(Integer.hashCode(key), buckets.length); }
    Integer get(int key) {
        for (Node p = buckets[bucket(key)]; p != null; p = p.next)
            if (p.key == key) return p.value;
        return null;
    }
    void put(int key, int value) {
        int i = bucket(key);
        for (Node p = buckets[i]; p != null; p = p.next)
            if (p.key == key) { p.value = value; return; }
        buckets[i] = new Node(key, value, buckets[i]);
    }
    void remove(int key) {
        int i = bucket(key); Node prev = null, p = buckets[i];
        while (p != null) {
            if (p.key == key) {
                if (prev == null) buckets[i] = p.next; else prev.next = p.next;
                return;
            }
            prev = p; p = p.next;
        }
    }
    // 开放寻址是另一方案；删除需墓碑或重排探测簇，不能直接清空。
    // 扩容须按新桶数重新散列；只比较哈希值不能代替比较 key。
}
```

## 02 时间和空间复杂度

均匀散列下操作期望 O(1+n/B)，碰撞最坏 O(n)；空间 O(B+n)。只有装载因子 n/B 受控时才可简写期望 O(1)。
