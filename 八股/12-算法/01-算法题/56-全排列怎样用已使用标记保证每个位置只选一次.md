# 56 全排列怎样用已使用标记保证每个位置只选一次

输入值互异；返回全部排列，不修改输入；空输入返回一个空排列。

## 01 Java 核心代码

集合与工具类型来自 java.util。

```java
public static List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> answer = new ArrayList<>();
    permuteDfs(nums, new boolean[nums.length], new ArrayList<>(), answer);
    return answer;
}

private static void permuteDfs(int[] nums, boolean[] used, List<Integer> path,
                               List<List<Integer>> answer) {
    if (path.size() == nums.length) {
        answer.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        used[i] = true;
        path.add(nums[i]);
        permuteDfs(nums, used, path, answer);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}
```

## 02 复杂度

- 时间：O(n·n!)，包含每个完整排列复制n个元素和递归层的候选检查
- 空间：辅助空间 O(n)，含used、路径和递归栈；输出 O(n·n!)
