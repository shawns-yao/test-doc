# 02 前 K 个高频元素，如何改成求第 2 个高频元素？

## 01 核心代码

按频次降序、同频按数值升序排名；topK 返回有序前 K 名。严格第二大频次另返回全部并列元素。

```java
import java.util.*;

static Map<Integer, Integer> counts(int[] a) {
    Map<Integer, Integer> freq = new HashMap<>();
    for (int x : a) freq.merge(x, 1, Integer::sum);
    return freq;
}
static List<Integer> topK(int[] a, int k) {
    Map<Integer, Integer> f = counts(a);
    if (k < 0 || k > f.size()) throw new IllegalArgumentException();
    Comparator<Integer> worstFirst = (x, y) -> {
        int c = Integer.compare(f.get(x), f.get(y));
        return c != 0 ? c : Integer.compare(y, x);
    };
    PriorityQueue<Integer> heap = new PriorityQueue<>(worstFirst);
    for (int x : f.keySet()) {
        heap.offer(x);
        if (heap.size() > k) heap.poll();
    }
    List<Integer> answer = new ArrayList<>();
    while (!heap.isEmpty()) answer.add(heap.poll());
    Collections.reverse(answer);
    return answer;
}
static int secondByRank(int[] a) { return topK(a, 2).get(1); }
static List<Integer> strictSecondFrequency(int[] a) {
    Map<Integer, Integer> f = counts(a);
    int first = 0, second = 0;
    for (int c : f.values()) {
        if (c > first) { second = first; first = c; }
        else if (c < first && c > second) second = c;
    }
    List<Integer> answer = new ArrayList<>();
    for (var e : f.entrySet()) if (e.getValue() == second) answer.add(e.getKey());
    return answer; // 无严格次高频次时为空，返回顺序不限
}
```

## 02 时间和空间复杂度

令 n 为输入长度、u 为不同元素数。topK 期望时间 O(n+u log(K+1)+K log(K+1))，空间 O(u+K)；按元素取第二名和严格第二频次均为期望 O(n+u) 时间、O(u) 空间。
