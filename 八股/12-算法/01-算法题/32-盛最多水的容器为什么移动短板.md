# 32 盛最多水的容器为什么移动短板

高度非负；用 long 保存面积。

## 01 Java 核心代码

```java
public static long maxArea(int[] height) {
    int left = 0, right = height.length - 1;
    long best = 0;
    while (left < right) {
        best = Math.max(best,
                (long) (right - left) * Math.min(height[left], height[right]));
        if (height[left] <= height[right]) left++;
        else right--;
    }
    return best;
}
```

## 02 复杂度

- 时间：O(n)，每轮至少缩小一个边界
- 空间：O(1)，无递归
