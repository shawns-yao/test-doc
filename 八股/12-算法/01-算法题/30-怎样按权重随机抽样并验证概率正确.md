# 30 怎样按权重随机抽样并验证概率正确

## 01 核心 Java 代码

前提：非负整数权重，总权重为正且不超过 long 上限；有放回抽样，预处理结果复用。

```java
import java.util.concurrent.ThreadLocalRandom;

static long[] buildPrefix(long[] weights) {
    if (weights.length == 0) throw new IllegalArgumentException("empty");
    long[] prefix = new long[weights.length];
    long sum = 0;
    for (int i = 0; i < weights.length; i++) {
        if (weights[i] < 0) throw new IllegalArgumentException("negative weight");
        sum = Math.addExact(sum, weights[i]);
        prefix[i] = sum;
    }
    if (sum == 0) throw new IllegalArgumentException("all zero");
    return prefix;
}

// prefix 由 buildPrefix 构建后不再修改；有放回抽样，非密码学用途。
static int pickIndex(long[] prefix) {
    long r = ThreadLocalRandom.current().nextLong(prefix[prefix.length - 1]);
    int lo = 0, hi = prefix.length - 1;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (prefix[mid] > r) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
```

---

## 02 复杂度

时间：预处理 O(n)，每次抽样 O(log n)。

空间：前缀数组 O(n)，每次抽样额外 O(1)。
