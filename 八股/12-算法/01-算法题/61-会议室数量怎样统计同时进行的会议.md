# 61 会议室数量怎样统计同时进行的会议

区间采用[start,end)，且start<end，结束时刻等于下一场开始时可复用；不修改输入。

## 01 Java 核心代码

集合与工具类型来自 java.util。

```java
public static int minMeetingRooms(int[][] intervals) {
    int[][] sorted = intervals.clone(); // 只排序引用，不修改内层区间
    Arrays.sort(sorted, Comparator.comparingInt(a -> a[0]));
    PriorityQueue<Integer> ending = new PriorityQueue<>();
    int rooms = 0;
    for (int[] meeting : sorted) {
        while (!ending.isEmpty() && ending.peek() <= meeting[0]) ending.poll();
        ending.offer(meeting[1]);
        rooms = Math.max(rooms, ending.size());
    }
    return rooms;
}
```

---

## 02 复杂度

- 时间：O(n log n)，排序和每场会议的入堆/出堆；峰值同时开会数就是最少房间数
- 空间：O(n)，含排序引用副本、排序辅助空间及堆；无递归业务调用
