# 41 合并两个有序链表怎样复用节点

沿用ListNode定义；两链表非递减、无环且不共享物理节点；复用节点会修改输入连接。

## 01 Java 核心代码

```java
public static ListNode mergeTwoLists(ListNode a, ListNode b) {
    ListNode dummy = new ListNode(0), tail = dummy;
    while (a != null && b != null) {
        if (a.val <= b.val) {
            tail.next = a;
            a = a.next;
        } else {
            tail.next = b;
            b = b.next;
        }
        tail = tail.next;
    }
    tail.next = a != null ? a : b;
    return dummy.next;
}
```

---

## 02 复杂度

- 时间：O(m+n)，最坏逐个取两链表节点
- 空间：O(1) 辅助空间，结果复用原节点；无递归
