# 44 验证二叉搜索树怎样传递祖先边界

沿用TreeNode定义；严格BST，不允许重复键；节点值为int。

## 01 Java 核心代码

```java
public static boolean isValidBST(TreeNode root) {
    return validBST(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

private static boolean validBST(TreeNode node, long lower, long upper) {
    if (node == null) return true;
    if (node.val <= lower || node.val >= upper) return false;
    return validBST(node.left, lower, node.val)
            && validBST(node.right, node.val, upper);
}
```

---

## 02 复杂度

- 时间：最坏 O(n)，每个节点至多检查一次
- 空间：递归栈 O(h)，平衡树 O(log n)，退化树 O(n)；极深树应换显式栈避免Java栈溢出
