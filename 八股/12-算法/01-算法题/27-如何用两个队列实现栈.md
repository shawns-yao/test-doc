# 27 如何用两个队列实现栈

## 01 核心代码

只用队尾入、队首出；空栈 pop/top 抛 NoSuchElementException。

```java
import java.util.*;

static class TwoQueueStack {
    Queue<Integer> main = new ArrayDeque<>(), spare = new ArrayDeque<>();
    void push(int x) {
        spare.offer(x);
        while (!main.isEmpty()) spare.offer(main.remove());
        Queue<Integer> tmp = main; main = spare; spare = tmp;
    }
    int pop() { return main.remove(); }
    int top() { return main.element(); }
    boolean empty() { return main.isEmpty(); }
}
```

---

## 02 时间和空间复杂度

push 时间 O(n)，pop/top/empty 时间 O(1)；空间 O(n)。连续 n 次 push 最坏 O(n²)。
