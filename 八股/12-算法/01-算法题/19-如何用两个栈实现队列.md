# 19 如何用两个栈实现队列

## 01 核心代码

空队列 pop/peek 抛 NoSuchElementException。

```java
import java.util.*;

static class TwoStackQueue {
    final Deque<Integer> in = new ArrayDeque<>(), out = new ArrayDeque<>();
    void push(int x) { in.push(x); }
    void moveIfNeeded() {
        if (out.isEmpty()) while (!in.isEmpty()) out.push(in.pop());
    }
    int pop() { moveIfNeeded(); return out.pop(); }
    int peek() { moveIfNeeded(); return out.element(); }
    boolean empty() { return in.isEmpty() && out.isEmpty(); }
}
```

---

## 02 时间和空间复杂度

入队 O(1)；出队/查看摊还 O(1)、单次最坏 O(n)；空间 O(n)。
