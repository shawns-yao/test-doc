# 20 反转链表 / 每 m 个反转 / 隔 K 反转怎么做？

## 01 核心代码

无环链表，改指针；分组尾部不足 k 保持原序。“隔 K”明确为反转 K 个、跳过 K 个交替。

```java
import java.util.*;

static class ListNode {
    int val; ListNode next;
    ListNode(int val) { this.val = val; }
}

static ListNode reverse(ListNode head) {
    ListNode prev = null;
    while (head != null) {
        ListNode next = head.next; head.next = prev; prev = head; head = next;
    }
    return prev;
}
static ListNode reverseGroups(ListNode head, int k, boolean alternating) {
    if (k <= 0) throw new IllegalArgumentException();
    ListNode dummy = new ListNode(0); dummy.next = head;
    ListNode before = dummy; boolean reverse = true;
    while (true) {
        ListNode end = before;
        for (int i = 0; i < k && end != null; i++) end = end.next;
        if (end == null) break;
        if (!reverse) before = end;
        else {
            ListNode oldHead = before.next, after = end.next;
            ListNode prev = after, curr = oldHead;
            while (curr != after) {
                ListNode next = curr.next; curr.next = prev; prev = curr; curr = next;
            }
            before.next = end; before = oldHead;
        }
        if (alternating) reverse = !reverse;
    }
    return dummy.next;
}
static ListNode reverseKGroup(ListNode h, int k) { return reverseGroups(h, k, false); }
static ListNode reverseAlternatingK(ListNode h, int k) { return reverseGroups(h, k, true); }
```

## 02 时间和空间复杂度

整体反转、每 K 组反转、交替反转均为时间 O(n)、额外空间 O(1)。
