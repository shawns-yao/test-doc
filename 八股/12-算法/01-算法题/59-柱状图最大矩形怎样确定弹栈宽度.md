# 59 柱状图最大矩形怎样确定弹栈宽度

柱宽1、高度非负；用long存面积；虚拟末尾高度−1确保清栈。

## 01 Java 核心代码

```java
public static long largestRectangleArea(int[] heights) {
    int n = heights.length, top = -1;
    int[] stack = new int[n];
    long best = 0;
    for (int i = 0; i <= n; i++) {
        int current = i == n ? -1 : heights[i];
        while (top >= 0 && heights[stack[top]] >= current) {
            int height = heights[stack[top--]];
            int left = top < 0 ? -1 : stack[top];
            long width = (long) i - left - 1;
            best = Math.max(best, width * height);
        }
        if (i < n) stack[++top] = i;
    }
    return best;
}
```

## 02 复杂度

- 时间：O(n)，每个下标入栈、出栈各一次；相等高度弹出旧柱，由新柱继续覆盖更宽范围
- 空间：O(n)，单调栈，无递归
