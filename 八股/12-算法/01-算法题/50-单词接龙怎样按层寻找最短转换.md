# 50 单词接龙怎样按层寻找最短转换

所有词等长、仅小写英文字母；返回路径中的单词数，无解0；起终点相同时约定1。

## 01 Java 核心代码

集合与工具类型来自 java.util。

```java
public static int ladderLength(String beginWord, String endWord, List<String> wordList) {
    if (beginWord.equals(endWord)) return 1;
    Set<String> unused = new HashSet<>(wordList);
    if (!unused.contains(endWord)) return 0;
    Deque<String> queue = new ArrayDeque<>();
    queue.addLast(beginWord);
    unused.remove(beginWord);
    int words = 1;
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            String current = queue.removeFirst();
            char[] chars = current.toCharArray();
            for (int p = 0; p < chars.length; p++) {
                char original = chars[p];
                for (char c = 'a'; c <= 'z'; c++) {
                    if (c == original) continue;
                    chars[p] = c;
                    String candidate = new String(chars);
                    if (!unused.remove(candidate)) continue;
                    if (candidate.equals(endWord)) return words + 1;
                    queue.addLast(candidate);
                }
                chars[p] = original;
            }
        }
        words++;
    }
    return 0;
}
```

## 02 复杂度

- 时间：期望 O(N·Σ·L²)，N为词典词数、L为词长、Σ=26；每词试 L·Σ 个候选，Java构造字符串和首次哈希均为 O(L)，不是无条件 O(NL)
- 空间：活跃辅助空间 O(NL)，包含集合/队列及生成的词字符串；无递归。累计临时分配可达 O(N·Σ·L²)，不等于峰值空间
