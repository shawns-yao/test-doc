# 04 合并区间的解题思路是什么？

## 01 核心代码

闭区间 [l,r]，l≤r，端点相接也合并；允许重排输入数组。

```java
import java.util.*;

static int[][] mergeIntervals(int[][] a) {
    if (a.length == 0) return new int[0][];
    Arrays.sort(a, Comparator.comparingInt(x -> x[0]));
    List<int[]> result = new ArrayList<>();
    int left = a[0][0], right = a[0][1];
    for (int i = 1; i < a.length; i++) {
        if (a[i][0] <= right) right = Math.max(right, a[i][1]);
        else {
            result.add(new int[]{left, right});
            left = a[i][0]; right = a[i][1];
        }
    }
    result.add(new int[]{left, right});
    return result.toArray(int[][]::new);
}
```

## 02 时间和空间复杂度

时间 O(n log n)；额外空间 O(n)，包含 Java 对象数组排序的辅助空间，另有最多 O(n) 输出。
