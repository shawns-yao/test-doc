# 25 滑动窗口最大值怎么做？

## 01 核心代码

1≤K≤n；返回每个连续 K 元素窗口的最大值。

```java
import java.util.*;

static int[] maxSlidingWindow(int[] a, int k) {
    if (k <= 0 || k > a.length) throw new IllegalArgumentException();
    Deque<Integer> deque = new ArrayDeque<>();
    int[] result = new int[a.length - k + 1];
    for (int i = 0; i < a.length; i++) {
        while (!deque.isEmpty() && deque.peekFirst() <= i - k) deque.removeFirst();
        while (!deque.isEmpty() && a[deque.peekLast()] <= a[i]) deque.removeLast();
        deque.addLast(i);
        if (i >= k - 1) result[i - k + 1] = a[deque.peekFirst()];
    }
    return result;
}
```

---

## 02 时间和空间复杂度

时间 O(n)；工作空间 O(K)，另有 O(n-K+1) 输出。
