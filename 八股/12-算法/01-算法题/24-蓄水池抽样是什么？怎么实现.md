# 24 蓄水池抽样是什么？怎么实现？

## 01 核心代码

Java 17+；对记录出现位置等概率、不放回抽 K 条；N<K 返回全部记录，K=0 返回空；N 不超过 long 上限。

```java
import java.util.*;

static <T> List<T> reservoir(Iterator<T> stream, int k, java.util.random.RandomGenerator rng) {
    if (k < 0) throw new IllegalArgumentException();
    List<T> pool = new ArrayList<>();
    if (k == 0) return pool;
    long seen = 0;
    while (stream.hasNext()) {
        T item = stream.next();
        seen = Math.incrementExact(seen);
        if (pool.size() < k) pool.add(item);
        else {
            long j = rng.nextLong(seen); // [0, seen)，避免直接取模造成偏差
            if (j < k) pool.set((int)j, item);
        }
    }
    return pool;
}
```

---

## 02 时间和空间复杂度

K>0 时遍历时间 O(N)，空间 O(min(K,N))；K=0 时 O(1)。K=1 即单样本蓄水池。
