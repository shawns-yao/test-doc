# 21 二叉树子结构怎么做

## 01 核心代码

空 B 不算子结构；B 匹配结束后允许 A 仍有额外节点。

```java
import java.util.*;

static class TreeNode {
    int val; TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}

static boolean isSubStructure(TreeNode a, TreeNode b) {
    if (a == null || b == null) return false;
    return match(a, b) || isSubStructure(a.left, b) || isSubStructure(a.right, b);
}
static boolean match(TreeNode a, TreeNode b) {
    if (b == null) return true;
    return a != null && a.val == b.val && match(a.left, b.left) && match(a.right, b.right);
}
```

---

## 02 时间和空间复杂度

A 有 n 个节点、B 有 m 个节点：最坏时间 O(nm)，递归空间保守 O(hA+hB)。
