# 52 打家劫舍怎样推导选与不选的状态转移

金额为非负int；房屋排成直线，相邻不能同时选择；返回long总额。

## 01 Java 核心代码

```java
public static long rob(int[] nums) {
    long beforePrevious = 0L, previous = 0L;
    for (int money : nums) {
        long current = Math.max(previous, beforePrevious + money);
        beforePrevious = previous;
        previous = current;
    }
    return previous;
}
```

## 02 复杂度

- 时间：O(n)，每间房只计算一次“选当前”与“不选当前”的最大值
- 空间：O(1)，两个前缀状态，无递归
