# 49 省份数量怎样统计图的连通分量

输入为n×n对称邻接矩阵，1表示连接；不修改输入。

## 01 Java 核心代码

集合与工具类型来自 java.util。

```java
public static int findCircleNum(int[][] connected) {
    int n = connected.length, provinces = 0;
    boolean[] visited = new boolean[n];
    Deque<Integer> queue = new ArrayDeque<>();
    for (int start = 0; start < n; start++) {
        if (visited[start]) continue;
        provinces++;
        visited[start] = true;
        queue.addLast(start);
        while (!queue.isEmpty()) {
            int city = queue.removeFirst();
            for (int other = 0; other < n; other++) {
                if (connected[city][other] == 1 && !visited[other]) {
                    visited[other] = true; // 入队时标记，避免重复入队
                    queue.addLast(other);
                }
            }
        }
    }
    return provinces;
}
```

## 02 复杂度

- 时间：O(n²)，每个城市出队时扫描矩阵一行；不能套邻接表 O(V+E) 而忽略矩阵扫描
- 空间：O(n) 辅助空间，含visited和队列；输入矩阵不计，无递归
