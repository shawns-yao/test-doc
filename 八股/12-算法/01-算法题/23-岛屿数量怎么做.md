# 23 岛屿数量怎么做？

## 01 核心代码

规则 0/1 字符网格，仅四方向连通；原地将陆地标记成水。

```java
import java.util.*;

static int numIslands(char[][] grid) {
    if (grid.length == 0 || grid[0].length == 0) return 0;
    int m = grid.length, n = grid[0].length, result = 0;
    int[] dr = {1, -1, 0, 0}, dc = {0, 0, 1, -1};
    Deque<int[]> queue = new ArrayDeque<>();
    for (int r = 0; r < m; r++) for (int c = 0; c < n; c++) {
        if (grid[r][c] != '1') continue;
        result++; grid[r][c] = '0'; queue.offer(new int[]{r, c});
        while (!queue.isEmpty()) {
            int[] p = queue.remove();
            for (int d = 0; d < 4; d++) {
                int nr = p[0] + dr[d], nc = p[1] + dc[d];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == '1') {
                    grid[nr][nc] = '0'; queue.offer(new int[]{nr, nc});
                }
            }
        }
    }
    return result;
}
```

## 02 时间和空间复杂度

时间 O(mn)；队列最坏空间 O(mn)。不允许改输入时另用 O(mn) visited；不能把染色后的 0 直接当原始水域计算周长。
