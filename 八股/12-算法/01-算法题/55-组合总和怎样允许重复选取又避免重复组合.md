# 55 组合总和怎样允许重复选取又避免重复组合

候选为互不相同的正整数、target非负；每种数可无限使用；复制数组后排序，不改输入。

## 01 Java 核心代码

集合与工具类型来自 java.util。

```java
public static List<List<Integer>> combinationSum(int[] candidates, int target) {
    int[] sorted = candidates.clone();
    Arrays.sort(sorted);
    List<List<Integer>> answer = new ArrayList<>();
    combineDfs(sorted, 0, target, new ArrayList<>(), answer);
    return answer;
}

private static void combineDfs(int[] nums, int start, int remaining,
                               List<Integer> path, List<List<Integer>> answer) {
    if (remaining == 0) {
        answer.add(new ArrayList<>(path));
        return;
    }
    for (int i = start; i < nums.length && nums[i] <= remaining; i++) {
        path.add(nums[i]);
        combineDfs(nums, i, remaining - nums[i], path, answer); // i可再次使用
        path.remove(path.size() - 1);
    }
}
```

## 02 复杂度

- 时间：O(n log n+nV+K·H)，V为递归调用次数、K为结果数、H为最大组合长度（候选非空时≤floor(target/最小面额)）。V最坏为指数级；K·H计答案复制，不把枚举算法写成线性
- 空间：辅助空间 O(n+H)，含排序副本、路径、递归栈；输出另计 O(K·H)。候选空时直接无结果（target=0则一个空组合）
