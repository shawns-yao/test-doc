# 54 分割等和子集为什么要倒序更新背包

沿用原题正整数及总和≤20000；每个位置最多使用一次。

## 01 Java 核心代码

```java
public static boolean canPartition(int[] nums) {
    int total = 0;
    for (int x : nums) total += x;
    if ((total & 1) != 0) return false;
    int target = total / 2;
    boolean[] reachable = new boolean[target + 1];
    reachable[0] = true;
    for (int x : nums) {
        for (int sum = target; sum >= x; sum--) {
            reachable[sum] |= reachable[sum - x]; // 倒序，来源仍是上一轮状态
        }
    }
    return reachable[target];
}
```

---

## 02 复杂度

- 时间：O(nS)，S为总和的一半；这是依赖数值S的伪多项式界
- 空间：O(S)，一维可达表，无递归
