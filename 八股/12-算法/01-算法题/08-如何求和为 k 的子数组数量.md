# 08 如何求和为 `k` 的子数组数量？

## 01 核心代码

统计非空连续子数组；允许负数；前缀和及计数用 long。

```java
import java.util.*;

static long subarraySum(int[] a, long k) {
    Map<Long, Long> count = new HashMap<>();
    count.put(0L, 1L);
    long sum = 0, answer = 0;
    for (int x : a) {
        sum += x;
        // k 限定为可与当前前缀和安全做 long 减法的业务范围
        answer += count.getOrDefault(sum - k, 0L);
        count.merge(sum, 1L, Long::sum);
    }
    return answer;
}
```

## 02 时间和空间复杂度

期望时间 O(n)；空间 O(n)。输入为 int 数组；k 与前缀和差值需在 long 范围内。
