# 34 最长连续序列怎样保证每段只扩展一次

按数值连续，不要求输入下标连续；重复值不增加长度。

## 01 Java 核心代码

集合与工具类型来自 java.util。

```java
public static int longestConsecutive(int[] nums) {
    Set<Integer> values = new HashSet<>();
    for (int x : nums) values.add(x);
    int best = 0;
    for (int start : values) { // 遍历去重后的集合，避免重复扩展
        if (start != Integer.MIN_VALUE && values.contains(start - 1)) continue;
        int x = start, length = 1;
        while (x != Integer.MAX_VALUE && values.contains(x + 1)) {
            x++;
            length++;
        }
        best = Math.max(best, length);
    }
    return best;
}
```

## 02 复杂度

- 时间：期望 O(n)：每个不同值仅在所属连续段被扩展一次
- 空间：O(u)，u 为不同值数量，最坏 O(n)；无递归
