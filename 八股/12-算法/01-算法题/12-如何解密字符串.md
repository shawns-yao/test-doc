# 12 如何解密字符串？

## 01 核心代码

按合法的 k[片段] 嵌套编码解码；k 为正 int，普通字符不含数字/括号；限制输出长度与嵌套深度。

```java
import java.util.*;

static String decode(String s, int maxOutput, int maxDepth) {
    if (maxOutput < 0 || maxDepth < 0) throw new IllegalArgumentException();
    Deque<Integer> repeats = new ArrayDeque<>();
    Deque<StringBuilder> prefixes = new ArrayDeque<>();
    StringBuilder current = new StringBuilder();
    int number = 0;
    for (char c : s.toCharArray()) {
        if (c >= '0' && c <= '9') {
            number = Math.addExact(Math.multiplyExact(number, 10), c - '0');
        } else if (c == '[') {
            if (prefixes.size() >= maxDepth || number <= 0) throw new IllegalArgumentException();
            repeats.push(number); prefixes.push(current);
            number = 0; current = new StringBuilder();
        } else if (c == ']') {
            if (prefixes.isEmpty()) throw new IllegalArgumentException();
            int times = repeats.pop();
            StringBuilder outer = prefixes.pop();
            if ((long)outer.length() + (long)times * current.length() > maxOutput)
                throw new IllegalArgumentException("output too large");
            if (!current.isEmpty()) for (int j = 0; j < times; j++) outer.append(current);
            current = outer;
        } else {
            if (current.length() == maxOutput) throw new IllegalArgumentException("output too large");
            current.append(c);
        }
    }
    if (!prefixes.isEmpty()) throw new IllegalArgumentException();
    return current.toString();
}
```

## 02 时间和空间复杂度

输入长 n、输出长 L、深度 d：逐层复制的保守时间 O(n+dL)，空间 O(n+L+d)。不把展开题误写为无条件 O(n)。
