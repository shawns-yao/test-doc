# 06 如何实现原地矩阵置零？

## 01 核心代码

规则矩阵，允许原地修改；空矩阵直接返回。

```java
import java.util.*;

static void setZeroes(int[][] a) {
    if (a.length == 0 || a[0].length == 0) return;
    int m = a.length, n = a[0].length;
    boolean rowZero = false, colZero = false;
    for (int j = 0; j < n; j++) rowZero |= a[0][j] == 0;
    for (int i = 0; i < m; i++) colZero |= a[i][0] == 0;
    for (int i = 1; i < m; i++) for (int j = 1; j < n; j++)
        if (a[i][j] == 0) { a[i][0] = 0; a[0][j] = 0; }
    for (int i = 1; i < m; i++) for (int j = 1; j < n; j++)
        if (a[i][0] == 0 || a[0][j] == 0) a[i][j] = 0;
    if (rowZero) Arrays.fill(a[0], 0);
    if (colZero) for (int[] row : a) row[0] = 0;
}
```

---

## 02 时间和空间复杂度

时间 O(mn)；额外空间 O(1)。
