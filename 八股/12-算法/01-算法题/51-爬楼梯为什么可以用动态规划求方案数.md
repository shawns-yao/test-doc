# 51 爬楼梯为什么可以用动态规划求方案数

每次走1或2级；0≤n≤91，n=0约定有一种空走法；long避免int结果溢出。

## 01 Java 核心代码

```java
public static long climbStairs(int n) {
    if (n < 0 || n > 91) throw new IllegalArgumentException("n must be 0..91");
    if (n <= 1) return 1L;
    long previous2 = 1L, previous1 = 1L;
    for (int step = 2; step <= n; step++) {
        long current = previous1 + previous2;
        previous2 = previous1;
        previous1 = current;
    }
    return previous1;
}
```

## 02 复杂度

- 时间：O(n)，每一级只计算一次
- 空间：O(1)，滚动保存两个状态；无递归。若改任意精度整数，需另计大整数运算与存储成本
