# 39 两数相加怎样逐位处理链表进位

ListNode含int val、ListNode next及ListNode(int)构造器。输入无环、每节点0–9，低位在前；新建结果不改输入。

## 01 Java 核心代码

```java
public static ListNode addTwoNumbers(ListNode a, ListNode b) {
    ListNode dummy = new ListNode(0), tail = dummy;
    int carry = 0;
    while (a != null || b != null || carry != 0) {
        int sum = carry;
        if (a != null) { sum += a.val; a = a.next; }
        if (b != null) { sum += b.val; b = b.next; }
        tail.next = new ListNode(sum % 10);
        tail = tail.next;
        carry = sum / 10;
    }
    return dummy.next;
}
```

---

## 02 复杂度

- 时间：O(max(m,n))，m、n 为两链表长度
- 空间：辅助空间 O(1)，新结果占 O(max(m,n))；无递归
