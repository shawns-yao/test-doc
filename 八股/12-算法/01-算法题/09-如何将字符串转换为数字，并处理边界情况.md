# 09 如何将字符串转换为数字，并处理边界情况？

## 01 核心代码

按 atoi：跳过前导普通空格，至多一个符号，读取 ASCII 数字，越界截断到 int 边界；s 非 null。

```java
import java.util.*;

static int atoi(String s) {
    int i = 0, sign = 1;
    while (i < s.length() && s.charAt(i) == ' ') i++;
    if (i < s.length() && (s.charAt(i) == '+' || s.charAt(i) == '-'))
        sign = s.charAt(i++) == '-' ? -1 : 1;
    long value = 0, limit = sign == 1 ? Integer.MAX_VALUE : -(long)Integer.MIN_VALUE;
    while (i < s.length()) {
        char c = s.charAt(i);
        if (c < '0' || c > '9') break;
        int digit = c - '0';
        if (value > (limit - digit) / 10)
            return sign == 1 ? Integer.MAX_VALUE : Integer.MIN_VALUE;
        value = value * 10 + digit;
        i++;
    }
    return (int)(sign * value);
}
```

---

## 02 时间和空间复杂度

时间 O(n)；额外空间 O(1)。
