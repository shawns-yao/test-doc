# 63 麻将常规和牌怎样用计数回溯判断

仅教学判定：34种牌（0–8万、9–17筒、18–26条、27–33字牌），每种0–4张，总计14张，无癞子、无杠、无已副露面子，只判四个面子加一对将；字牌不能顺子。不覆盖七对、十三幺、番种或具体地区完整和牌规则。

## 01 Java 核心代码

集合与工具类型来自 java.util。

```java
public static boolean isStandardMahjongHand(int[] tiles) {
    if (tiles == null || tiles.length != 34) return false;
    int total = 0;
    for (int count : tiles) {
        if (count < 0 || count > 4) return false;
        total += count;
    }
    if (total != 14) return false;
    int[] counts = tiles.clone();
    Map<String, Boolean> memo = new HashMap<>();
    for (int pair = 0; pair < 34; pair++) {
        if (counts[pair] < 2) continue;
        counts[pair] -= 2;
        boolean ok = mahjongMelds(counts, memo);
        counts[pair] += 2;
        if (ok) return true;
    }
    return false;
}

private static boolean mahjongMelds(int[] counts, Map<String, Boolean> memo) {
    int first = 0;
    while (first < 34 && counts[first] == 0) first++;
    if (first == 34) return true;
    String key = Arrays.toString(counts);
    Boolean cached = memo.get(key);
    if (cached != null) return cached;
    boolean ok = false;
    if (counts[first] >= 3) {
        counts[first] -= 3;
        ok = mahjongMelds(counts, memo);
        counts[first] += 3;
    }
    // 首个剩余牌只能作为顺子起点；不可跨花色，字牌不可成顺
    if (!ok && first < 27 && first % 9 <= 6
            && counts[first + 1] > 0 && counts[first + 2] > 0) {
        counts[first]--; counts[first + 1]--; counts[first + 2]--;
        ok = mahjongMelds(counts, memo);
        counts[first]++; counts[first + 1]++; counts[first + 2]++;
    }
    memo.put(key, ok);
    return ok;
}
```

## 02 复杂度

- 时间：设牌种T、牌数H、访问到的不同剩余状态S；枚举将牌O(T)，每状态扫描/编码O(T)，期望时间 O(T²+S·T)。粗略不记忆化上界 O(T²·2^(H/3))，来自每层刻子/顺子两分支；本题固定T=34、H=14，不把一般回溯宣称线性
- 空间：O(S·T+T+H)，含记忆化键、计数副本、至多H/3层递归及各层编码；输入不修改
