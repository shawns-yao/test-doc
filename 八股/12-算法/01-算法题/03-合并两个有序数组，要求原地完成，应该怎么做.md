# 03 合并两个有序数组，要求原地完成，应该怎么做？

## 01 核心代码

两数组非递减；a 长度为 m+n，前 m 项有效，b 有 n 项；修改 a。

```java
import java.util.*;

static void merge(int[] a, int m, int[] b, int n) {
    int i = m - 1, j = n - 1, write = m + n - 1;
    while (j >= 0) {
        a[write--] = i >= 0 && a[i] > b[j] ? a[i--] : b[j--];
    }
}
```

## 02 时间和空间复杂度

时间 O(m+n)；额外空间 O(1)。
