# 57 子集怎样用起点或选不选枚举全部结果

输入值互异；返回所有子集，包含空集；不修改输入。

## 01 Java 核心代码

集合与工具类型来自 java.util。

```java
public static List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> answer = new ArrayList<>();
    subsetsDfs(nums, 0, new ArrayList<>(), answer);
    return answer;
}

private static void subsetsDfs(int[] nums, int start, List<Integer> path,
                               List<List<Integer>> answer) {
    answer.add(new ArrayList<>(path));
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        subsetsDfs(nums, i + 1, path, answer);
        path.remove(path.size() - 1);
    }
}
```

---

## 02 复杂度

- 时间：O(n·2^n)，2^n个结果复制的总元素数为 n·2^(n−1)（n≥1）
- 空间：辅助空间 O(n)，路径与递归栈；输出 O(n·2^n)，包含结果列表结构
