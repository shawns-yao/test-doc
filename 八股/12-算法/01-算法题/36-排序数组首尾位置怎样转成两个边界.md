# 36 排序数组首尾位置怎样转成两个边界

数组非递减；无目标返回[−1,−1]。

## 01 Java 核心代码

```java
public static int[] searchRange(int[] nums, int target) {
    int first = bound(nums, target, false);
    if (first == nums.length || nums[first] != target) return new int[]{-1, -1};
    return new int[]{first, bound(nums, target, true) - 1};
}

// strict=false：第一个 >= target；strict=true：第一个 > target
private static int bound(int[] nums, int target, boolean strict) {
    int left = 0, right = nums.length; // 半开区间
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] > target || (!strict && nums[mid] == target)) right = mid;
        else left = mid + 1;
    }
    return left;
}
```

## 02 复杂度

- 时间：O(log n)，两次二分不改变数量级
- 空间：O(1)，结果两个下标，无递归
