# 11 如何在有序矩阵中查找目标数？

## 01 核心代码

规则矩阵，每行、每列分别非递减；不要求按行展开后整体有序。

```java
import java.util.*;

static boolean searchMatrix(int[][] a, int target) {
    if (a.length == 0 || a[0].length == 0) return false;
    int row = 0, col = a[0].length - 1;
    while (row < a.length && col >= 0) {
        if (a[row][col] == target) return true;
        if (a[row][col] > target) col--;
        else row++;
    }
    return false;
}
```

---

## 02 时间和空间复杂度

时间 O(m+n)；额外空间 O(1)。
