# 15 如何用整数凑出目标值，并求最少需要多少个数？

## 01 核心代码

面额均为正整数，可无限次使用；恰好凑出非负 amount，不可达返回 -1；amount+1 可分配。

```java
import java.util.*;

static int coinChange(int[] coins, int amount) {
    if (amount < 0 || amount == Integer.MAX_VALUE) throw new IllegalArgumentException();
    for (int c : coins) if (c <= 0) throw new IllegalArgumentException();
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1); dp[0] = 0;
    for (int sum = 1; sum <= amount; sum++)
        for (int c : coins)
            if (c <= sum && dp[sum - c] <= amount)
                dp[sum] = Math.min(dp[sum], dp[sum - c] + 1);
    return dp[amount] > amount ? -1 : dp[amount];
}
```

---

## 02 时间和空间复杂度

面额数 c、目标 A：时间 O(cA)，空间 O(A)，属于伪多项式复杂度。
