# 01 TCP 和 UDP 有什么区别？请从连接方式、可靠性和传输速度等方面比较。

## 01 核心回答


**连接与语义：**TCP 是面向连接的可靠字节流，建立连接后不保留应用消息边界；UDP 是无连接的数据报，每次发送保留独立报文边界，接收端可以知道一份数据报的范围。

**可靠性机制：**TCP 通过三次握手、序列号、确认应答、超时重传、滑动窗口、流量控制和拥塞控制，保证尽可能有序、无重复地交付，但可靠交付以连接和网络可用为边界，连接失败时仍可能无法交付，ACK 也不是业务事务已提交的证据；UDP 不保证到达、顺序和去重，也不负责重传与拥塞控制，可靠性需要应用层补足。

**性能差异：**TCP 有握手、状态维护、确认和重传开销，队头阻塞可能放大丢包影响；UDP 首包快、头部小、可广播/多播，应用可以自行选择重传、纠错、拥塞策略，但“UDP 更快”不是无条件结论，网络拥塞时仍会丢包；选型应围绕丢失能否补偿、过期消息是否值得重传和拥塞行为，而非只比较头部字节数。

**场景选择：**文件传输、网页、数据库连接、支付等需要完整一致的数据优先 TCP；实时音视频、在线游戏、DNS、物联网遥测等更关注时延或可容忍少量丢包的场景常用 UDP。UDP 的“无连接”指协议层不握手，socket API 仍可调用 `connect` 来固定默认对端。QUIC 在 UDP 之上实现可靠传输、多路复用和 TLS，兼顾两者特性。

**面试追问：**TCP 为什么是字节流（协议不理解业务消息）；UDP 是否任何场景都不好（不是，低时延和自定义可靠性是优势）；TCP 如何避免拥塞（慢启动、拥塞避免、快速重传和恢复等机制）。
