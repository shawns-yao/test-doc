# 01 HTTP 请求报文由哪些部分组成？请说明请求行、请求头、空行和请求体的作用。

## 01 核心回答


**整体结构：**HTTP/1.x 请求报文由请求行、请求头、空行和请求体四部分组成；HTTP/2、HTTP/3 的 HTTP 编码采用二进制帧，但语义上仍对应方法、目标、头字段和数据。

**请求行：**包含方法、请求目标和协议版本，例如 `GET /users?page=1 HTTP/1.1`。方法表达意图，目标包含路径和查询参数，版本决定协议能力；`Host` 在 HTTP/1.1 中通常必须出现，用于虚拟主机路由。

**请求头：**描述报文元数据和协商信息，如 `Content-Type`、`Content-Length`、`Authorization`、`Cookie`、`Accept`、缓存和连接控制字段。头字段不等于业务参数，业务参数应按约定放在路径、查询参数或请求体中。

**空行与请求体：**空行（`CRLF CRLF`）标记请求头结束；请求体承载 JSON、表单、文件等数据，长度由 `Content-Length` 或分块传输编码确定。`GET` 通常没有请求体，但协议并非绝对禁止，服务端是否处理要看接口约定。

**常见误区：**查询参数属于请求目标，不是请求头；HTTPS 只保护传输过程，服务端解密后仍要做鉴权、参数校验和重放防护；请求体可为空，不能据此判断请求是否成功。

---

## 02 理解补充与边界校订

本题的文本报文格式特指 HTTP/1.x，HTTP/2 和 HTTP/3 的帧属于 HTTP 协议编码，不是 TCP/UDP 传输层的帧。Content-Length 与 Transfer-Encoding 同时存在涉及请求走私风险，代理与后端必须一致解析。GET 的内容没有普遍定义语义，兼容性未知时不要设计依赖 GET 请求体的接口。
