# 03 常见 HTTP 状态码有哪些？

## 01 核心回答


200 OK

成功——请求正常处理。

201 Created

创建成功（POST 建资源）。

204 No Content

成功但无返回体（DELETE）。

301 / 302

永久重定向 / 临时重定向。

304 Not Modified

协商缓存命中，用本地缓存。

400 Bad Request

请求参数错误。

401 / 403

缺少有效认证凭据 / 理解请求但拒绝执行（不保证已认证）。

404

资源不存在。

429

请求过多（限流）。

500 / 502 / 503

服务端错误 / 网关错误 / 服务不可用（过载）。

**追问：**401 和 403 区别（认证 vs 授权）；302 和 307 的区别（方法是否保持）；503 常见于什么（服务过载/熔断）。

---

## 02 常见简写的边界订正

401 表示缺少有效认证凭据，规范要求带适当的 WWW-Authenticate 挑战；403 是服务器理解请求但拒绝执行，不保证用户已经完成认证。404 也可用于隐藏资源存在性。400 不只用于参数错误，还可表示其他客户端请求格式或消息问题。

301/302 在历史兼容行为中可能将 POST 改为 GET；307/308 明确保留方法和请求体。204 不能带响应内容，304 表示可复用已缓存表示，并非服务器又返回一份完整页面。

---

## 03 前端处理重点

fetch 收到 4xx/5xx 通常仍会兑现为 Response，不等同网络层 Promise 拒绝；需要检查 HTTP 状态并结合业务错误信息。429/503 可以携带 Retry-After，重试还需判断请求是否可安全重放，不能对所有失败请求无限重试。
