# 01 HTTP 是什么？

## 01 核心回答


**概念：**HTTP（超文本传输协议）是应用层**请求-响应**协议，客户端发请求、服务端回响应；无状态、可扩展（头部/方法/状态码可演进），基于 TCP（HTTP/3 基于 QUIC/UDP）。

**核心要素：**① 方法：GET/POST/PUT/DELETE/PATCH/HEAD/OPTIONS；② 状态码：2xx 成功、3xx 重定向、4xx 客户端错误、5xx 服务端错误；③ 头部：请求头/响应头携带元数据（Content-Type、Cache-Control、Cookie 等）；④ 版本演进：1.0/1.1/2.0/3.0（见 [[八股/06-计算机基础/00-计算机基础导航|计算机网络]] 4.2）。

**工作原理：**URL 解析 → 建立连接 → 发送请求（请求行 + 头 + 体）→ 服务端处理 → 返回响应（状态行 + 头 + 体）→ 关闭或复用连接。

**追问：**GET 和 POST 的区别（语义 + 缓存 + 幂等）；HTTP 和 HTTPS 区别（见 4.1 网络协议）；无状态怎么维持会话（Cookie/Session/Token）。

## 02 协议语义与传输编码分开说

HTTP 的方法、状态码和字段语义跨版本延续，但“请求行、状态行加头部文本”是 HTTP/1.x 的报文表达方式；HTTP/2、HTTP/3 采用帧与伪首部，不能把文本格式当作所有版本的线上结构。

GET 的安全与幂等是协议期望语义，不代表服务端实现必然无副作用，也不是隐私保证；POST 不是“因为有请求体所以更安全”。HTTPS 保护传输过程，业务授权、输入校验和日志脱敏仍需应用实现。
