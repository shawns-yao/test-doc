# 06 页面脉冲虚化动画是怎么实现的？

## 01 核心回答


**概念：**“脉冲虚化”通常是元素周期性放大 + 模糊（或亮度/透明度脉动）的动效，常见于呼吸灯、加载状态、焦点提示。

**实现方式（CSS 为主，推荐）：**① `@keyframes` 定义动画：scale 从 1 到 1.2 循环 + `filter: blur()` 或 `opacity` 脉动；② `animation: pulse 2s ease-in-out infinite` 挂到元素；③ 性能：优先考虑 **transform/opacity**；filter 的绘制及合成成本需实测，`will-change` 仅在需要时使用。

**JS 方案（需要交互控制时）：**requestAnimationFrame 循环改 CSS 变量（如 blur 值）——避免 setInterval 掉帧；或 Web Animations API（`element.animate()`）。

**追问：**为什么用 transform 不用 width/height（合成器线程 vs 主线程布局）；filter blur 性能开销大吗（大元素费 GPU，避免全屏 blur）；怎么控制动画暂停（animation-play-state）。

---

## 02 动画性能订正

transform 与 opacity 通常更有机会仅在合成阶段更新，但是否提升为合成层取决于浏览器与页面条件；filter 尤其大面积 blur 不能保证便宜或完全脱离主线程。避免把“不触发布局”等同于“没有绘制和显存成本”。用 Performance 与图层信息实测，必要时缩小模糊区域或使用预先生成的效果资源。

will-change 不是常驻加速开关，大量元素长期提升图层会增加内存和管理成本。requestAnimationFrame 与刷新节奏协作，但回调仍可能运行在繁忙的主线程上，不保证不掉帧。

---

## 03 体验与可访问性

支持 prefers-reduced-motion，用户要求减少动态效果时可停止脉冲或改成静态提示。离屏或不可见时暂停不必要动画；若动画表示加载，还要提供可理解的文本状态，不能只依赖视觉闪动。
