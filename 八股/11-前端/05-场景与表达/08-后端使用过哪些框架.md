# 08 后端使用过哪些框架？

## 01 核心回答


**回答（按真实经历组织）：**

**Java 方向：**Spring Boot（核心框架）——Web（Spring MVC）、事务（Spring 事务）、AOP；持久层 MyBatis/MyBatis-Plus；工具：Lombok、MapStruct、Guava；测试 JUnit/Mockito。

**中间件/组件：**Redis（缓存/锁）、RocketMQ/Kafka（异步）、Elasticsearch（搜索）、Nacos（配置/注册）、XXL-Job（定时任务）。

**表述技巧：**每个框架讲「用它解决了什么 + 踩过什么坑」——比罗列框架名有说服力；按项目讲（项目 A 用了 X 解决 Y）。

**追问：**Spring Boot 和 Spring 的区别（自动装配 + starter）；MyBatis 和 JPA 选型（见 1.5）；框架源码读过哪些（面试加分项，讲一个即可）。

## 02 把技术清单变成能力证据

只列实际接触过的项目依赖，按“独立实现过、参与使用过、仅了解”区分掌握程度。每个重点技术准备一个功能入口、一项配置选择和一个遇到的边界问题；没有做过的缓存锁、消息可靠投递或调度故障不要从清单中直接认领。

Spring Boot、持久层框架、测试工具和 Redis 等中间件不是同一类别，分类能避免堆名词。若没有读过完整源码，可坦诚讲实际追过的类或调用链，并区分官方机制和自己项目的配置。
