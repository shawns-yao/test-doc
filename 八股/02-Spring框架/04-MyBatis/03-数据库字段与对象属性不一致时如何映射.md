# 03 数据库字段与对象属性不一致时如何映射

## 01 原有详细回答

**字段与属性不一致：**① 开启驼峰映射（`map-underscore-to-camel-case`，`user_name → userName`）；② `resultMap` 显式映射；③ 别名（`SELECT user_name AS userName`）。

## 02 映射发生在哪个阶段

SQL 执行后返回列标签和列值，MyBatis 再将它们映射到 Java 对象的属性或构造参数。SQL 别名改变结果集列标签；驼峰映射把下划线命名转换为属性命名；resultMap 明确声明列与属性之间的对应关系。这些机制处理返回值，不改变参数绑定或 SQL 执行权限。

## 03 怎么选择与验证

简单单表、命名统一时可以使用自动映射；少量命名差异可以通过查询别名说明；复杂连接、嵌套对象、集合或重复列名需要显式 resultMap 与明确的列前缀。连接两张表都返回 id 时，若不使用唯一列标签或映射约束，很容易把值映射错对象。

验证不只检查字段是否非空，还要覆盖 NULL、类型转换、同名列、嵌套关系和多行合并。自动映射选项必须与实际 MyBatis 配置一致，不能只改 Java 属性名后假定框架一定找到对应列。

## 04 口述版

我先确认问题发生在 SQL 参数还是返回结果。字段与属性不一致属于结果映射，可用 SQL 别名、驼峰映射或 resultMap；简单命名差异优先保持约定，复杂对象图显式映射，并用包含空值和同名列的查询测试验证。
