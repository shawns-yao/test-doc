
线程私有：程序计数器，Java 虚拟机栈，本地方法栈
线程共享：堆，方法区

为什么需要将内存分成这些区域：本质是因为 JVM 运行程序，需要存储不同生命周期的数据

1.程序计数器 PC Register
	记录当前线程下一条需要执行的字节码指令的位置。

因为 CPU 不可能一次性的将整个方法执行完，比如线程可能执行到了 A，就被 OS 切走了，过一会线程重新拿到了 CPU，它得知道我刚刚执行到了哪里
而这个位置就是程序计数器记录的

并且程序计数器是 JVM 运行内存区域中唯一一个 JVM 规范没有规定的 Out Of MemeoryError 的区域

2.Java 虚拟机栈 JVM Stack
	一个线程调用 Java 方法时的执行现场

每调用一个方法，就会创建一个栈帧，栈帧中包括
	局部变量表
	操作数栈

3.本地方法栈 Native Method Stack
	Java 不一定所有的代码都是 Java 写的，比如有些底层会调用 C/C++

4.堆 Heap
	核心是存放 Java 对象和引用

为什么堆是线程共享的？
	因为多个线程可能会访问同一个对象，所以堆是共享的，这也就是为什么 Java 会有线程安全，锁等问题了

5.方法区 Method Area
	方法区解决的问题是 JVM 需要知道一个类型到底长什么样子

比如，JVM 需要知道这个类叫做什么，父类是谁 ，实现了哪些接口，有哪些字段，有哪些方法等，这些都是属于类级别的信息，而不是某一个对象的信息

方法区中还存在一个运行时常量池
