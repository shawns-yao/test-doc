# 03 常见的垃圾回收算法有哪些？请说明标记-清除、复制、标记-整理和分代收集算法的特点。

## 01 核心回答


**标记-清除**
先标记存活对象，再清除不可达对象。实现简单，但需要两次遍历（标记 + 清除），且会产生大量内存碎片。

**复制**
把存活对象复制到另一块连续区域，再清空原区域。不会产生碎片，但需要额外空间，适合存活对象较少的区域；部分传统分代配置用 Eden:Survivor:Survivor = 8:1:1 辅助理解，但比例可调、可自适应，G1 不按固定连续三块工作，不能泛化为所有 HotSpot 的 10% 固定开销。

**标记-整理**
先标记存活对象，再将存活对象向一端移动，最后清理边界外空间。能够减少碎片，但移动对象成本更高。

**分代收集**
根据对象生命周期把堆划分为新生代和老年代，新生代使用更适合大量短命对象的复制思想，老年代使用标记-清除或标记-整理等算法。它利用了大多数对象朝生夕死、少数对象长期存活的规律。

现代垃圾收集器通常是这些算法的组合，例如年轻代复制、老年代标记整理；具体策略还要结合吞吐量、延迟和堆大小选择收集器。

**常见追问：**为什么老年代也可以复制？高存活率会增加复制成本和预留空间，但 G1 等仍会疏散老年代 Region，是否采用取决于整体收集器设计；新生代 8:1:1 分区中 Survivor 空间不足时，对象会通过分配担保机制直接进入老年代。

---

## 02 从成本推导选择

标记成本随需要遍历的存活对象图增长，清除通常要处理被管理区域；复制主要搬运幸存对象，因此在多数对象已死亡时很划算。整理把空闲空间集中起来，减少分配失败，但必须处理对象移动后的引用。

分代是利用对象寿命分布的策略，不是与复制/整理互斥的第四种搬运算法。代际引用需要写屏障、卡表/记忆集维护，才能回收年轻代时避免全堆扫描；这是获得较小回收集合的额外成本。

## 03 校正与依据

保留传统比例作为示例，去掉“老年代不能复制”的绝对结论。算法名称不能直接推出并发程度或停顿时长，二者取决于屏障和阶段设计。
