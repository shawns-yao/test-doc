## Java 相关复习原则

- 集合问题优先关注数据结构、复杂度、扩容和线程安全边界。
- 并发问题优先关注原子性、可见性、有序性、锁和线程协作。
- JVM 问题优先关注运行机制、内存管理和线上排查。
- 跨专题问题只保留一份主文档，通过 wikilink 从其他专题进入。
