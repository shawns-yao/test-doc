# 07 雪花算法如何保证唯一性并处理时钟回拨

## 01 核心机制

雪花类 ID 将时间戳、工作节点标识和同时间单位内序列拼接。唯一性来自这几个字段组合不重复，而不是仅来自时间戳。各实现位数不同，应按可用年限、部署规模和每毫秒峰值容量分配；趋势有序不等于跨所有机器严格单调。

## 02 时钟回拨的处理

先比较当前墙上时间与上次已用时间。很短的回拨可有界等待追平，但等待预算不能写死为通用 5ms；较大回拨可以拒绝发号并告警。也可使用受持久化高水位保护的逻辑时间，前提是序列不复用且耗尽时等待或拒绝。切换备用节点标识必须确保标识独占、旧实例不能继续使用。

## 03 重启与故障为什么更危险

只在进程内保存历史最大时间不够，重启会丢状态；机器 ID 重新分配也可能与旧进程重叠。必须有可靠租约/分配与隔离机制，或保存发号高水位并在恢复时跳过已使用区间。序列耗尽不能在同时间值下归零，时间倒退也不能只取最大值就断言唯一。

## 04 易错点与取舍

原材料把小回拨固定成 5ms、自旋、备用时钟源和“最大时间戳即唯一”列为通用处理，现限定为需验证的实现策略。NTP 调整要结合操作系统与时间服务具体配置，不能笼统要求一个 maxslew 参数。单调时钟适合测量等待时长，不直接给出跨机器统一的业务时间。允许跳号通常比冒险重复更合理。

## 05 面试口述

唯一性要同时保证时间窗口、机器标识和序列组合不重复。回拨我选择有界等待、拒绝或受保护的逻辑时间，并补齐重启高水位、标识租约和序列耗尽处理；数据库唯一约束做最后防线。
