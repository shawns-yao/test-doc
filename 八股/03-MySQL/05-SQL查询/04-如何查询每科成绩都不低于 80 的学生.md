# 04 如何查询每科成绩都不低于 80 的学生

## 01 核心回答

在每个学生都有完整、非 NULL 成绩记录且每科口径已确定的前提下，按学生分组并要求最低分至少 80。

```sql
-- ① 每科都不低于 80 的学生（先分组取最低分再过滤）
SELECT student_id
FROM score
GROUP BY student_id
HAVING MIN(score) >= 80;
```

## 02 为什么 MIN 可以表达全部满足

只要最小成绩不低于阈值，所有已参与聚合的成绩都满足阈值；反过来只要有一个低分，MIN 就能把该学生排除。不能写 WHERE score >= 80 后再分组，否则低分行被提前删去，可能误把部分课程达标当成全科达标。

## 03 NULL 与缺科的边界

MIN 忽略 NULL，只有已有行参与分组，因此原 SQL 不能证明“每一门应修课程都存在且及格”。若 NULL 表示不合格，需显式排除；若缺科也不合格，需把应修课程集合与成绩匹配，检查没有缺失或不达标项。COUNT(score)=COUNT(*) 只能排除已有行中的 NULL，不能发现完全缺失的课程。

## 04 面试追问

平均分超过 80 能否推出每科不低于 80？不能，某科高分可能抵消低分。没有任何成绩的学生是否满足？原查询不会返回，需要由题意决定是否应排除。多次考试如何处理？先选定每科最终成绩，再做全科判断。

## 05 面试口述

完整非空成绩集合可用 HAVING MIN(score)>=80；真正的“全部课程达标”还要确认缺科和 NULL，不让聚合函数忽略缺失造成误判。
