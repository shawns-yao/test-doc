**北京共绩科技有限公司**　　**AI 应用实习生**　　**2026.06–2026.09**

**项目：FDE Workstation——事件驱动的研发交付与故障诊断平台**  
**项目描述：** 面向 CI/CD 与 Kubernetes 故障处置场景，串联代码构建、应用部署、故障诊断和协同处置流程，通过确定性编排与 Diagnosis Agent 提升故障定位和恢复效率。  
**技术栈：** TypeScript｜Node.js｜Redis Streams｜PostgreSQL｜Docker｜Kubernetes｜Argo CD｜GitLab CI｜MCP｜JSON Schema

- **主导 Diagnosis Agent 的设计与实现，**构建“假设生成—证据规划—工具取证—根因排序”的诊断链路，综合 Kubernetes 状态、构建记录和运行日志分析候选根因，并通过证据引用与冲突校验增强诊断结果的可追溯性；在 **120 个故障样本**上 Top-3 根因命中率达到 **91.7%**，平均故障定位时间由 **18min 降至 7 min**。
    
- **参与建设 Redis Streams + PostgreSQL Outbox 可靠事件链路，**引入幂等提交、处理租约和 Fencing Token，支持消费者故障接管并拦截旧实例陈旧写入；在 **10 万级事件压测**中实现 **0 重复状态提交**，消费者故障后的平均接管时间控制在 **5 s 内**。
    
- 参与抽象统一状态迁移契约，分别约束 Pipeline 执行流程和 Collaboration 协同流程；通过实体锁、版本校验、迁移审计与非法状态拒绝统一并发语义，保证交付、诊断和协同链路中的状态一致性。
